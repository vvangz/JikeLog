# 即刻日志 v1.8.0 发布说明

> 发布日期：2026-11-24 · [下载](https://www.pingvv.top/download) · [GitHub Release](https://github.com/vvangz/JikeLog/releases/latest) · [完整变更记录](../../CHANGELOG.md)

本次更新带来全新品牌徽标「瞬刻书签」与全端自定义头像功能，从图标细节到个人形象全面焕新。

## 新功能

- **自定义头像（全端同步与离线缓存）**：
  - 在 **帐号页** 点击顶部头像或「资料 → 头像」，可从相册或本地文件选择 JPEG / PNG / WebP 图片设为自定义头像，也可随时一键恢复默认首字母头像。
  - 客户端自动居中裁切缩放并剥离 EXIF 隐私元数据后上传；头像同步展示在帐号页、侧栏底部与概览主卡（点击概览头像可直达帐号页），并支持本地缓存，离线打开同样清晰呈现。
- **全新品牌徽标「瞬刻书签 · J-Log Emblem」**：
  - 以深海群青至曜石靛蓝渐变衬托双层磨砂日志页、珠光银白无衬线「J」字标与天青四角星芒（✦），紧扣「即刻日志（JikeLog）」的品牌意象。
  - 统一更新 Android 应用图标、Windows 桌面图标、应用内导航徽标、官网与管理后台品牌标志。

## 升级

- **已安装 v1.7.0 的用户**：可直接在应用内通过 **概览顶部提示条** 或 **设置 → 检查更新** 一键下载、校验并覆盖安装 v1.8.0。
- **从更早版本升级**：请前往[下载页](https://www.pingvv.top/download)下载安装最新版本。

## 已知限制

- **Windows 版暂不支持短信验证**：验证码登录、找回密码与绑定手机号请在手机上操作。
- **推送未开通**：提醒只依靠本机通知，请在提醒时间前打开过一次 App 完成同步。
