# 即刻日志 v1.4.0 发布说明

> 发布日期：2026-10-26 · [下载](https://www.pingvv.top/download) · [GitHub Release](https://github.com/vvangz/JikeLog/releases/latest) · [完整变更记录](../../CHANGELOG.md)

官网改版。App 与 v1.3.0 相同，已安装 v1.3.0 的不需要升级。

## 官网

- **更简洁的设计**：以黑白灰为主，层次更清晰；支持浅色与深色主题。
- **新字体**：标题使用思源黑体，西文与数字使用 Geist。字体随网站一起提供，打开很快。
- **细腻的动效**：页面内容随滚动依次出现。系统开启"减少动态效果"时不播放动画。
- **更清爽的下载页**：文件名、SHA-256 与证书指纹收进"校验信息"，需要核对时展开即可。

## 升级

- **Android**：无需升级；新安装请从[下载页](https://www.pingvv.top/download)下载最新的 APK。
- **Windows**：无需升级；新安装请下载最新的 `.msix`，首次安装前导入签名证书。

## 已知限制

- **Windows 版暂不支持短信验证**：验证码登录、找回密码与绑定手机号请在手机上操作。
- **推送未开通**：提醒只依靠本机通知，请在提醒时间前打开过一次 App 完成同步。
