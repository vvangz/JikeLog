# 即刻日志 v1.6.0 发布说明

> 发布日期：2026-11-23 · [下载](https://www.pingvv.top/download) · [GitHub Release](https://github.com/vvangz/JikeLog/releases/latest) · [完整变更记录](../../CHANGELOG.md)

全面升级工作日志与笔记（含 Windows 版）的 Markdown 编辑体验，参考 Typora 补齐列表自动续接编号、实时语法高亮、常用快捷键与交互式预览，并同步修复服务端依赖安全更新。

## 新功能

- **实时语法高亮**：在工作日志和笔记的 Markdown 编辑框中输入时，标题按级别放大加粗，有序/无序/待办与引用标记即时着色，加粗、斜体、删除线、行内代码和代码块实时呈现层次。
- **Typora 风格输入规则**：
  - 有序列表、无序列表、待办清单与引用块按回车自动续接下一项；在有序列表中间回车会自动顺延后续同级编号；空项再按回车退出。
  - 行首输入 `[]`、`[ ]`、`[x]` 后按空格，自动生成 `- [ ] ` / `- [x] ` 待办项。
  - 输入 ```` ``` ```` 或 ```` ```语言 ```` 后按回车，自动补全闭合标记并将光标移入代码块内；代码块内部不会误触发列表续接。
- **丰富的快捷键与多行编辑**：支持 `Ctrl/Cmd+1~6`（标题切换）、`Ctrl/Cmd+0`（恢复正文）、`Ctrl/Cmd+B/I/`\`/`K`（加粗/斜体/行内代码/链接）、`Ctrl/Cmd+Shift+X/C/Q/7/8/9`（删除线/代码块/引用/有序/无序/待办）、`Tab`/`Shift+Tab`（单行及多行缩进）和 `Ctrl/Cmd+/`（切换编辑/预览）。
- **工具栏与预览升级**：工具栏补齐斜体、删除线、行内代码、链接、有序列表、引用、分隔线与缩进按钮，右侧固定插图与预览入口；预览中可直接点击待办复选框勾选完成。

## 安全与维护

- **服务端依赖升级**：升级 Go 至 1.27.4 与 `klauspost/compress` 至 v1.20.2，修复漏洞扫描报告的安全问题。

## 升级

- **Android**：从[下载页](https://www.pingvv.top/download)下载新版 APK，覆盖安装即可，数据不受影响。
- **Windows**：下载新版 `.msix` 双击安装；已导入过签名证书的无需再次导入。

## 已知限制

- **Windows 版暂不支持短信验证**：验证码登录、找回密码与绑定手机号请在手机上操作。
- **推送未开通**：提醒只依靠本机通知，请在提醒时间前打开过一次 App 完成同步。
