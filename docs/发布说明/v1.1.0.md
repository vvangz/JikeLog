# 即刻日志 v1.1.0 发布说明

> 发布日期：2026-10-23 · [下载](https://www.pingvv.top/download) · [GitHub Release](https://github.com/vvangz/JikeLog/releases/tag/v1.1.0) · [完整变更记录](../../CHANGELOG.md)

新增 **Windows 版**。它与 Android 版是同一个应用：用同一个账号登录，数据在手机和电脑之间实时同步。Android 版同时更新。

## 下载与安装

- **Windows**：要求 Windows 10（1809）及以上的 64 位系统。下载 `jikelog-1.1.0.msix` 与证书 `jikelog-windows.cer`。**第一次安装前**要先核对证书指纹并让电脑信任这张证书，以后升级不用再做，步骤见[使用说明第 9 章](../使用说明/09-Windows版.md)。
- **Android**：下载 `jikelog-1.1.0.apk` 直接覆盖安装，数据保留。

## 新功能

**Windows 版**
- 工作日志、笔记、备忘录、记账四个模块与 Android 版相同，多设备实时同步、离线可用。
- 备忘提醒由 Windows 通知弹出，App 关闭后照常提醒。
- 导出数据时选择保存的文件夹。
- 打开附件更安全：图片、PDF、Office 文档等用电脑上的默认应用打开，程序、脚本、含宏的文档等只打开所在文件夹；打开的是标记为"来自互联网"的副本。
- 窗口可以自由调整大小，较宽时侧栏常驻。

**两个平台**
- 键盘快捷键：Ctrl+F 搜索，Ctrl+N 在当前模块新建。Android 手机外接键盘时同样可用。
- 使用即刻日志自己的应用图标，替换了默认图标。

## 与 Android 版的区别

- 笔记只有 Markdown 编辑。在手机上用富文本写的笔记也以 Markdown 打开，内容不会丢失，回到手机上仍是富文本。
- 不提供"同步到系统日历"。

详见[使用说明第 9 章](../使用说明/09-Windows版.md)。

## 已知限制

- **证书**：Windows 版使用自签名证书，第一次安装前须手动信任，请务必先核对指纹。
- **短信、推送未开通**：同 v1.0.0。
