# 即刻日志 v1.0.0 发布说明

> 发布日期：2026-10-14 · [下载 APK](https://github.com/vvangz/JikeLog/releases/tag/v1.0.0) · [完整变更记录](../../CHANGELOG.md)

即刻日志的第一个正式版本。它是面向个人和企业员工的记录工具，包含**工作日志、笔记、备忘录、记账**四个模块，多台手机之间实时同步，断网也能使用。

## 下载与安装

- 在 [GitHub Release](https://github.com/vvangz/JikeLog/releases/tag/v1.0.0) 下载 `jikelog-1.0.0.apk`，要求 Android 8.0 及以上。
- 安装包由正式密钥签名。以后的版本可以直接覆盖安装，数据保留。
- 同一页面的 `.sha256` 文件可用于核对安装包是否完整。
- 以前装过开发测试版（调试签名）的手机，需要先卸载测试版再安装。两者签名不同，不能覆盖。

详细步骤见[快速上手](../使用说明/01-快速上手.md)。

## 功能一览

**工作日志**
- 日期、工作地点、工作内容和附件，随时修改并自动保存，可以关联笔记。
- 传输时在 HTTPS 之外再做一层应用层加密，存储时按账号加密。

**笔记**
- Markdown 与富文本两种编辑方式，支持代码块、表格、待办清单。
- 文件夹、标签、收藏；附件可以是图片、PDF、音频或任意文件。

**备忘录**
- 日期时间加内容，可以设置提前提醒；日历视图，并可写入手机系统日历。
- 提醒由手机本地闹钟按时弹出，断网、重启后照常提醒。

**记账**
- 收入、支出、转账、借贷；多个账户与两级分类。
- 分类占比、收支趋势、账户余额与净资产统计。

**通用**
- 多设备实时同步：同一字段以最后修改为准，不同字段自动合并，冲突时保留修订历史，可以查看并恢复。
- 全局搜索：覆盖四个模块，可以按模块、时间筛选，离线可用。
- 数据导出：工作日志（Excel、Markdown）、笔记（Markdown 与附件）、备忘录（ICS、CSV）、记账（Excel、CSV）以及全量 JSON。
- 浅色、深色、跟随系统三种主题；手机、平板和横屏都有对应布局。
- 注销账号会永久删除全部数据。

**管理后台（Web）**
- 仪表盘、用户列表与配置查看（只读，看不到用户的记录内容）、审计日志、管理员账号管理。

## 安全与数据保护

- 正式版只信任 Let's Encrypt 签发的服务器证书，被代理或抓包工具替换证书时拒绝连接。
- 密码使用 argon2id 存储；登录有失败锁定；每台设备的登录可以单独退出。
- 服务器数据每 14 天备份一次：数据库、附件和配置用管理员离线保存的密钥加密后，上传到另一地域的存储。服务器上没有解密密钥，被攻破也删不掉异地备份。

## 已知限制

- **域名备案进行中**：服务器域名的 ICP 备案通过之前，外网无法访问服务器，正式版 App 暂时连不上。备案通过后无需更新 App。（备案已于 2026-10-23 通过，服务器已可访问。）
- **短信未开通**：只能用用户名和密码注册、登录；验证码登录、绑定手机号、找回密码暂不可用。**忘记密码将无法找回**，请牢记用户名和密码。
- **推送未开通**：提醒只依靠手机本地通知。请在提醒时间前打开过一次 App 完成同步；提醒很多时定期打开 App，以便排上最近 64 个之后的提醒。
- **附件容量**：每个账号的附件总量上限为 8GB。
- **平台**：目前只有 Android 版，Windows 版在后续版本提供。
- **性能**：一次同步 500 条修改时，服务器端耗时约 0.36 秒（目标 0.2 秒），日常使用感知不到；用户增多时再升级服务器。
