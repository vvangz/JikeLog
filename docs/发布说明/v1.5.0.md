# 即刻日志 v1.5.0 发布说明

> 发布日期：2026-10-27 · [下载](https://www.pingvv.top/download) · [GitHub Release](https://github.com/vvangz/JikeLog/releases/latest) · [完整变更记录](../../CHANGELOG.md)

新增"概览"首页，打开 App 一屏看到各模块的近况。

## 新功能

- **概览首页**：登录后默认进入，也可以从侧栏最上方的"概览"进入。
  - 顶部显示问候语与今天的摘要，下方四个快捷按钮：写日志、新笔记、新备忘、记一笔。
  - **工作日志**：连续记录天数、本月篇数，以及按天的记录热力图。
  - **备忘录**：今日待办、已逾期、本周完成率，以及接下来的 3 条备忘。
  - **记账**：本月支出、收入与结余，近 30 天的支出走势，以及净资产。点击眼睛图标可以隐藏金额。
  - **笔记**：笔记总数、近 7 天编辑篇数、收藏数，以及最近编辑的 3 篇。
  - 点击卡片进入对应模块；统计全部由本机数据计算，离线也能看。
- **返回键回到概览**：在各模块、设置、帐号页按返回键回到概览，在概览页按返回键才退出 App。

## 升级

- **Android**：从[下载页](https://www.pingvv.top/download)下载新版 APK，覆盖安装即可，数据不受影响。
- **Windows**：下载新版 `.msix` 双击安装；已导入过签名证书的无需再次导入。

## 已知限制

- **Windows 版暂不支持短信验证**：验证码登录、找回密码与绑定手机号请在手机上操作。
- **推送未开通**：提醒只依靠本机通知，请在提醒时间前打开过一次 App 完成同步。
