# 即刻日志 v1.2.0 发布说明

> 发布日期：2026-10-24 · [下载](https://www.pingvv.top/download) · [GitHub Release](https://github.com/vvangz/JikeLog/releases/latest) · [完整变更记录](../../CHANGELOG.md)

即刻日志的官网 [www.pingvv.top](https://www.pingvv.top) 上线：产品介绍、Android 与 Windows 安装包下载、使用教程、更新日志、隐私政策与用户协议。

v1.2.1、v1.2.2 只修正了发布官网时的部署脚本，App 与 v1.2.0 相同，请直接安装最新版本。

## 新功能

- **官网下载**：安装包同时放在本站与 GitHub Release，本站下载更快。每个安装包都附 `.sha256` 校验文件；下载页显示 Windows 证书的指纹。
- **隐私政策与用户协议定稿**，自 2026 年 10 月 24 日起生效。App 中的文本与官网一致，更新后第一次打开 App 时会请你重新阅读并同意。

## 升级

- **Android**：下载最新的 APK 覆盖安装，数据保留。
- **Windows**：下载最新的 `.msix` 双击安装即可，不用再导入证书。

## 已知限制

- **短信未开通**：只能用用户名和密码注册、登录，**忘记密码将无法找回**。
- **推送未开通**：提醒只依靠本机通知，请在提醒时间前打开过一次 App 完成同步。
