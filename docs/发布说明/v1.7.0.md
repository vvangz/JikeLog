# 即刻日志 v1.7.0 发布说明

> 发布日期：2026-11-24 · [下载](https://www.pingvv.top/download) · [GitHub Release](https://github.com/vvangz/JikeLog/releases/latest) · [完整变更记录](../../CHANGELOG.md)

焕新全端视觉主题为「深海群青 × 冰雾石板」并更新应用图标，同时新增 Android 与 Windows 应用内覆盖更新能力，后续升级无需再手动访问官网下载。

## 新功能

- **全新群青主题与应用图标**：
  - 浅色主题采用深海群青主色与云雾白底色，深色主题采用雾蓝靛主色与深夜蓝灰底色，全部配色均满足 WCAG 2.2 对比度标准。
  - 更新 Android 与 Windows 应用图标为深海群青渐变圆角图标配天青亮点，同步更新管理后台与记账统计图表配色。
- **应用内自动检查与覆盖更新（Android / Windows）**：
  - 启动时在概览页静默检查新版本，发现更新时展示轻量提示条（可随时忽略）；也可随时在 **设置 → 检查更新** 或 **关于 → 检查更新** 中手动触发。
  - 应用内直接下载安装包并逐字节核对 SHA-256 校验值，通过后自动调起 Android 系统安装器或 Windows 应用安装程序完成覆盖升级，本机数据完整保留。

## 升级

- **从 v1.6.0 及更早版本升级**：本次仍需从[下载页](https://www.pingvv.top/download)下载安装 v1.7.0；升级至 v1.7.0 后，后续所有新版本均可直接在应用内一键覆盖更新。
- **Windows**：已导入过签名证书的无需再次导入。

## 已知限制

- **Windows 版暂不支持短信验证**：验证码登录、找回密码与绑定手机号请在手机上操作。
- **推送未开通**：提醒只依靠本机通知，请在提醒时间前打开过一次 App 完成同步。
