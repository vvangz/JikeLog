# 2026-11-23 · v1.6.0 · Markdown 编辑体验升级

## 目标

此前工作日志与笔记（Markdown 模式及 Windows 全量笔记）的编辑框仅提供最基础的文本输入与少量工具栏按钮，缺少列表自动续接编号、快捷输入规则、键盘快捷键和直观的排版反馈。本版参考 Typora 的使用习惯，全面升级共享的 `MarkdownEditor`，同时修复服务端依赖漏洞扫描告警。

## 完成项

### 输入规则（`shared/ui/markdown_input_formatter.dart`）

- **自动续接与编号顺延**：在有序列表（`1. `）、无序列表（`- `/`+ ` /`* `）、待办清单（`- [ ] ` / `- [x] `）与引用块（`> ` / `> > `）中按回车自动续接下一项；在有序列表中间按回车时，自动顺延后续同级列表项编号，同时保持更深缩进的子项不动。
- **退出列表/引用**：空列表项或空引用行按回车退出；位于正文中间时保留空行，不把后文粘上来。
- **待办快捷输入**：行首输入 `[]`、`[ ]`、`[x]`、`[X]` 或 `-[]` 后按空格，自动规范化为 `- [ ] ` 或 `- [x] `。
- **围栏代码块感知**：输入 ```` ``` ```` / ```` ```lang ```` / `~~~` 后按回车，在未闭合时自动补全闭合标记并将光标定位到代码块内部；处于围栏代码块内部时，禁用列表续接与待办快捷语法，避免误改代码。
- **输入法与粘贴保护**：只处理单字符用户输入，不改写粘贴内容或输入法组合中（composing）的文本。

### 实时语法高亮（`shared/ui/markdown_text_controller.dart`）

- 新增 `MarkdownTextEditingController`（继承 `TextEditingController`，零破坏性接入 `WorklogEditorPage` 与 `NoteEditorPage`）：
  - 严格保持源码字符与光标偏移 1:1 对应，并在输入法组合期间保留系统下划线。
  - 编辑态实时渲染标题字号层级、有序/无序/待办与引用标记着色、已完成待办删除线、加粗/斜体/删除线/链接样式、行内代码与围栏代码块等宽背景，浅色与深色主题均读取 `JkColors` 令牌。

### 工具栏、快捷键与交互式预览（`shared/ui/markdown_editor.dart`）

- **智能格式命令**：
  - 行内包裹（加粗、斜体、删除线、行内代码）支持开关切换：已被相同标记包裹时再触发一次自动取消。
  - 标题（`Ctrl/Cmd+1~6`、`Ctrl/Cmd+0`）与列表（有序/无序/待办）切换直接替换已有前缀，不再叠加出 `# ## ` 或 `1. - `；支持多行选区批量转换（多行有序列表自动按 `1. / 2. / 3.` 连续编号）与多行 `Tab` / `Shift+Tab` 缩进。
  - `Ctrl/Cmd+K` 智能插入链接：选中 URL 时填入地址栏，选中普通文字时高亮 `https://` 占位便于直接粘贴。
- **完整快捷键**：`Ctrl/Cmd+0..6`、`B`、`I`、`` ` ``、`K`、`Shift+X`、`Shift+C`、`Shift+Q`、`Shift+7/8/9`、`Tab`/`Shift+Tab`、`Ctrl/Cmd+/`（编辑/预览切换，编辑态与预览态均可用）。
- **工具栏布局**：左侧横向滚动放置紧凑编辑按钮（新增斜体、删除线、行内代码、链接、有序列表、引用、分隔线、增加/减少缩进），右侧固定扩展按钮（如笔记插入图片）与 **预览 / 编辑** 按钮，窄屏手机上无需滚动即可预览或插图。
- **交互式预览**：启用 `softLineBreak`，应用与主题一致的 `MarkdownStyleSheet`；预览中的待办复选框可直接点击切换 `[ ]` ↔ `[x]` 并写回源码（自动跳过代码块中的伪待办），笔记模式预览同时支持点击链接经安全确认后打开。

### 服务端依赖维护

- 将服务端 Go 版本与容器基础镜像升级至 `1.27.4`，并将 `github.com/klauspost/compress` 升级至 `v1.20.2`，消除 CI `govulncheck` 报告的漏洞告警。
