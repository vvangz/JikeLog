# 2026-10-11 · v0.6.0 · M5 记账

## 目标

需求第 7 条：
1. 记录收入、支出，以及转账和借贷。
2. 每笔记录包含金额、日期、分类和备注。
3. 提供分类占比、账户余额等统计。
4. 与其他模块一样多设备同步、加密传输与存储。

## 完成项

### 设计

见 [ADR-009](../架构/ADR/ADR-009-记账数据模型.md)：

- **同步实体**：账户、两级分类、借贷、流水，共四个。
- **金额**：新增字段类型 `KindMoney`，以"分"为单位的规范整数字符串。用字符串是为了能作为敏感字段加密，金额、名称、对方、备注、分类图标都加密。
- **流水类型**：收入、支出、转账（含手续费）、借出、借入、收款、还款，各自对余额与待收待还的影响都有明确定义。
- **预置分类**：ID 由账号确定地生成。字段时钟取固定的最早值，多台设备各自初始化时不重复、不冲突，也不会覆盖用户的修改。
- **统计**：全部在本地计算。

### 服务端（`server`）

- 在同步 schema 中登记四个实体，新增 `KindMoney`：规范写法、15 位以内、可设下限（流水金额 ≥ 1 分，手续费 ≥ 0）。
- 加密字段在解密后同样校验。

### 移动端（`apps/mobile`）

- **数据层**：
  - 金额工具：只用整数（分）计算，显示带千分位。输入最多两位小数，解析规则与服务端一致。
  - 模型、仓储、统计计算：余额、借贷待收待还、净资产、收支合计、分类占比、趋势。
  - `RecordStore.seed`：写入预置记录。
- **记账主界面**（三个页签）：
  - 流水：按月查看、按日分组，顶部为收入、支出与结余。
  - 统计：
    - 按月或按年查看。
    - 分类占比用饼图和排行展示，点一级分类可展开二级。
    - 收支趋势用柱状图展示，带图例。
  - 账户：净资产、各账户余额、待收与待还，账户的增改、隐藏与删除，借贷列表。
- **记一笔**：
  - 一个表单覆盖七种类型，分类分两级选择。
  - 默认选中上次使用的账户。
  - 校验字段约束，并检查收款、还款不超过待收、待还。
- **借贷详情**：
  - 查看金额与相关流水，记收款或还款。
  - 修改对方和到期日，标记结清，删除。
- **分类管理**：新增一级和二级分类、改名、换图标、隐藏。预置分类和已有流水的分类不能删除。

## 关键决策

| 决策 | 理由 |
|---|---|
| 金额存为以分为单位的整数字符串并加密 | 避免浮点误差；同步协议只能加密字符串字段；服务端不需要金额 |
| 预置分类 ID 由账号确定地生成，字段时钟取固定的最早值 | 多台设备同时初次使用不出现两份、不产生冲突版本；用户的修改永远比默认值新 |
| 已有流水的账户和分类只能隐藏，不能删除 | 历史流水与统计仍能显示名称；删除后留下的引用会让余额对不上 |
| 已结清的借贷不计入待收待还 | 允许减免或坏账，结清后净资产与列表显示一致 |
| 统计不存储、不上传 | 离线可用；金额在服务端是密文，本来也无法计算 |

## 问题与解决

| 问题 | 解决 |
|---|---|
| Flutter 的 foundation 库导出了名为 `Category` 的注解，与分类模型同名 | 模型改名为 `LedgerCategory` |
| 在数据库事务内安排同步，同步时报"事务已关闭" | drift 用 Zone 追踪事务，事务中启动的定时器回调仍在该 Zone。改为事务结束后再安排同步，并在代码中注明 |
| 窄屏、大字号时，每日合计、分类排行的金额溢出 | 金额在可用宽度内缩小显示；新增窄屏加 1.5 倍字号的测试，覆盖三个页签与借贷详情 |
| 对方修改对话框关闭时报 `attached` 断言 | 文本控制器在对话框退出动画结束前就被释放了，改由对话框自己持有并释放 |
| 用量到达上限，三个审查代理中途终止 | 额度重置后重新发起审查 |

## 审查记录

三个审查（通用、Flutter、安全）都没有 CRITICAL。HIGH 和 MEDIUM 已修复并补了测试，部分 LOW 一并处理。

| 级别 | 问题 | 处理 |
|---|---|---|
| HIGH | 预置分类的时钟带设备节点，第二台设备写入时，每个预置分类都会产生冲突版本 | 时钟改为与设备无关的固定值；新增服务端双设备测试 |
| HIGH | 修改已有流水时切到借贷，表单卡住无法保存 | 借贷类流水按原类型固定；已有的收支、转账不能改成借贷 |
| HIGH | 下拉框只在创建时读取初始值，切换收款和还款、或同步改变选项后显示过时的值，或触发断言 | 选项或当前值变化时重建下拉框 |
| MEDIUM | 切换类型后，隐藏的手续费仍参与校验，挡住保存 | 只有转账校验手续费；换类型时清掉专属字段 |
| MEDIUM | 流水已不存在时显示空白表单，保存时静默成功 | 显示"流水不存在"；修改不存在的流水报错 |
| MEDIUM | 收款、还款可以超过待收、待还，可以关联方向相反的借贷 | 仓储校验方向与上限，原因显示在表单中 |
| MEDIUM | 标记结清后仍计入净资产 | 已结清的借贷不再计入 |
| MEDIUM | 多步写入不在同一事务中，中途失败会留下孤立数据 | 借贷与首笔流水、删除借贷、删除分类都放进事务 |
| MEDIUM | 删除账户只按可解析的流水判断引用 | 按原始字段判断 |
| MEDIUM | 删除账户、分类没有确认 | 删除前确认 |
| MEDIUM | 到期当天就显示"已逾期" | 按日期比较 |
| MEDIUM | 图表只用颜色区分；饼图文字对比度不足；分类图标选择没有读屏标签，点按区域偏小 | 加图例和读屏合计；按底色选文字颜色；补读屏标签，点按区域改为 48dp |
| MEDIUM | 统计在每次构建时都完整重算 | 改为派生 provider，只在数据或查看条件变化时计算 |
| MEDIUM（安全） | 服务端可见的元数据，以及可推算的预置分类 ID，ADR 没有说明 | ADR 写明；分类图标改为加密 |
| LOW（一并处理） | 客户端金额解析比服务端宽松；读到金额不为正的流水时会算错余额；展开的分类被删除后无法返回 | 全部修复 |
