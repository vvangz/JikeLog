### 2. 全栈自定义头像

- **数据库与对象存储（Go 后端）**：
  - 新增迁移 `server/db/migrations/00006_user_avatar.sql`，在 `users` 表增加 `avatar_key`、`avatar_mime`、`avatar_etag`；新增 sqlc 查询 `UpdateUserAvatar` 与 `ClearUserAvatar`。
  - 对象存储 `storage.Store` 新增流式写入 `Put`，头像对象存放在 `u/{userID}/avatar/{uuid}.{ext}`，天然被账号注销时的 `DeletePrefix("u/<userID>/")` 自动清理。
  - 新增 OpenAPI 契约与实现：
    - `User.avatarVersion`（可选 16 位 SHA-256 哈希前缀，作为多端缓存键）；
    - `GET /api/v1/me/avatar`（按真实格式输出 `image/jpeg|png|webp`，附带 `ETag`、`Cache-Control: private, max-age=3600`、`X-Content-Type-Options: nosniff`）；
    - `PUT /api/v1/me/avatar`（独立 3 MiB 请求体上限，限流 20 次/小时，严格按文件头魔数与宽高 ≤ 4096px 校验 JPEG/PNG/WebP 并拦截 SVG/MIME 伪装与超大分辨率图片，替换时自动清理旧对象）；
    - `DELETE /api/v1/me/avatar`（恢复默认头像并删除对象）。
- **Flutter 客户端（Android / Windows）**：
  - `ApiClient` 新增 `getBytes` 支持二进制鉴权下载与 401 自动刷新重试；`ApiException.fromDio` 兼容字节流错误信封解码。
  - 新增 `AvatarService`（`apps/mobile/lib/features/account/avatar_service.dart`）：使用 `dart:ui` 自动居中裁切为 ≤512×512 PNG（同步剥离 EXIF 隐私元数据），内置内存 + 磁盘离线缓存，上传成功即刻落盘免额外下载，退出登录或注销账号时自动清理磁盘缓存。
  - 新增通用 `UserAvatar` 组件（`apps/mobile/lib/shared/ui/user_avatar.dart`），接入账号页（头部可编辑头像 + 资料卡片「头像」入口 + 更换/恢复默认操作面板）、侧栏底部署名区以及概览顶部主卡（点击头像直达账号页）。

## 关键决策

- **头像路由走 `/api/v1/me/avatar` 而非公开 URL**：用户头像属于个人账号信息，经鉴权接口返回并由客户端按 `(userId, avatarVersion)` 持久化到本地磁盘，兼顾隐私安全与离线秒开体验。
- **头像存储前缀复用 `u/{userID}/`**：账号注销时无需额外维护清理逻辑，即可保证对象存储零残留。
- **零新增第三方图像处理依赖**：直接利用 Flutter 内置 `dart:ui` 重绘裁切输出 PNG，以及 Go 标准库 `image/png`、`image/jpeg` 和轻量 WebP 头解析校验分辨率，保持前后端依赖精简。
