### 服务端（`server`）

- **数据库**：pgx v5 连接池；goose 迁移内嵌进二进制，通过 `cmd/migrate` 执行（镜像中为 `jikelog-migrate`）；查询由 sqlc 生成（`scripts/gen-db.sh`，版本固定在脚本里，不进 `go.mod`）。
- **表结构**：
  - `users`：用户名不区分大小写唯一，手机号部分唯一索引。
  - `devices`：一行代表一个安装实例上的一次登录会话，记录刷新令牌哈希和 `tokens_valid_after`。
  - `user_settings`。
- **接口**：共 18 个，见 `server/api/openapi.yaml` 中的 auth 和 account 标签。
- **认证**（详见 [ADR-003](../架构/ADR/ADR-003-认证会话与令牌.md)）：
  - 密码用 argon2id 哈希，限制并发计算数；参数过时的旧哈希在登录时自动升级。
  - Access Token 15 分钟；Refresh Token 每次刷新都轮换，30 秒宽限期内的重试是幂等的，超过宽限期重复使用视为泄露，对应设备会被下线。
  - 设备下线、修改密码在数据库事务内生效，不依赖缓存。
  - 默认拒绝：只有白名单里的路由可以匿名访问，测试校验白名单与接口契约一致。
- **短信验证码**：
  - Redis 中只存 HMAC 值。
  - 限制：同一号码 60 秒冷却、每天 10 条；同一 IP 每小时 20 条；每个验证码最多尝试 5 次。
  - 找回密码时不透露手机号是否已注册。
  - 开发环境使用模拟通道，验证码打印在日志里；staging 和 production 禁止使用模拟通道。
- **防暴力破解**：
  - 登录失败按"账号+网络"满 5 次、"账号"累计满 20 次两级锁定，短信登录可以解除锁定。
  - 身份校验同样有限流。
  - 单 IP 限额按接口分别计算，IPv6 按 /64 归并。
- **HTTP 层**：
  - 业务错误统一映射为信封和状态码，422 返回字段级错误，429 带 `Retry-After`。
  - 请求体上限 1MB；CORS 白名单；客户端 IP 只按可信代理解析。
- **配置**：新增数据库、Redis、JWT 密钥和轮换、短信通道、人机验证通道、CORS 等配置项。配置非法时拒绝启动，错误信息不回显密码。

### 移动端（`apps/mobile`）

- **导航外壳**：
  - 手机宽度：点击左上角入口图标，侧栏自上而下展开为浮层，带遮罩；点击遮罩或按返回键收起。
  - 600–840：常驻图标栏，入口图标展开完整侧栏。
  - ≥840：常驻完整侧栏，可以收起为图标栏。
  - 侧栏上方是四个模块，下方是设置、帐号和登录状态。开启"减少动态效果"时不播放展开动画。读屏可以通过语义动作激活入口。
- **自绘图标**：工作日志、笔记、备忘录、记账、设置、帐号，统一 24 栅格、1.5 描边、圆角端点。
- **通用组件**（`shared/ui`）：按钮（主要、次要、文字、危险四种，带加载态）、表单字段（服务端字段错误直接显示在对应输入框下）、密码框、带倒计时的验证码框、空状态、错误状态（可重试）、骨架屏、轻提示、确认弹窗、页面容器。
- **页面**：
  - 隐私政策与用户协议同意页：同意前不初始化任何第三方 SDK。
  - 登录（密码 / 验证码）、注册、完善注册、找回密码。
  - 设置（主题、字号、一周起始、默认提醒、关于）。
  - 帐号（昵称、手机号、修改密码、登录设备、退出、注销）。
- **数据与状态**：
  - Riverpod 3 + go_router 18；路由守卫是一个纯函数（`redirectFor`）。
  - 令牌存放在 Android Keystore（flutter_secure_storage）。
  - 离线优先：有令牌但网络不通时，用缓存的账号信息进入应用；设置先保存在本机，联网后自动同步。
  - `ApiClient` 解包统一信封；令牌过期时只刷新一次（single-flight），然后重试原请求。
- **Android 网络配置**：正式构建只允许 HTTPS，并且只信任系统证书；调试构建允许明文访问 10.0.2.2 / localhost。
- **接口客户端**：手写，用契约测试与 `openapi.yaml` 对齐（[ADR-004](../架构/ADR/ADR-004-Dart客户端与契约测试.md)）。

## 关键决策

| 决策 | 原因 |
|---|---|
| 设备会话以数据库为准，每个请求做一次主键查询 | 初版依赖 Redis 标记，审查指出两个问题：事务提交后写标记失败会留下仍有效的令牌；Redis 数据丢失后已下线的令牌会恢复有效（ADR-003） |
| 刷新宽限期内返回同一结果（加密缓存） | 并发刷新或丢包重试时，如果每次都换发新令牌，客户端可能拿着失效的令牌被静默登出 |
| 绑定手机号需要当前密码 | 防止有人用盗来的登录态绑定自己的号码，再用短信登录或找回密码永久接管账号 |
| 号码已被占用时，绑定验证码同样返回"已发送"但实际不发送 | 防止借此探测号码是否已注册 |
| sqlc 不放进 `go.mod`，版本固定在脚本中 | sqlc 依赖很多，会扩大服务端模块的依赖图和漏洞扫描范围 |
| 首个迁移 `00001` 在发布前直接修改 | 该迁移还没有发布或部署过，直接修改比追加一个修复迁移更清楚。从 v0.2.0 起，已发布的迁移只追加、不修改 |
| Dart 客户端手写 + 契约测试 | 接口规模小，生成器需要 Java 或 build_runner，引入成本高于收益（ADR-004） |
| 阿里云短信和人机验证放到 v0.9.0 | 需要企业资质，签名和模板也要审核。在此之前，staging 和 production 的配置校验会拒绝启动，避免误用模拟通道 |

## 问题与解决

1. **仓库刚创建时的推送不触发 Actions**：工作流已经注册，但没有生成运行记录。给 CI 加上 `workflow_dispatch` 并手动触发后正常运行。
2. **lefthook 在 Windows 上报 `syntax error: unexpected end of file`**：lefthook 把多行 `run` 当作参数传给 sh 时，内嵌的双引号被破坏。把逻辑挪到 `scripts/hooks/*.sh` 后解决。
3. **testcontainers 在 Docker Desktop for Windows 上启动失败**：
   - Ryuk 一直等不到 "Started"。解决办法是在 Windows 上关闭 Ryuk，由 `testinfra.Main` 在测试结束后显式停止容器；CI（Linux）保留 Ryuk。
   - 多个测试包并行时，Docker 主机自动探测偶尔会落到不支持的 rootless 策略。解决办法是显式指定命名管道 `DOCKER_HOST`，并加上重试。
   - 两项环境变量都必须在首次调用 testcontainers 之前设置，因为它只读取一次配置。
4. **sqlc 把带 `IS NULL` 语义的时间参数推断成指针类型**：在查询里加 `@now::timestamptz` 显式类型转换。
5. **侧栏外壳在手机和平板宽度下内容区无法点击**：这是组件测试发现的真实缺陷。外壳的 `Stack` 中只有一个非定位子组件，即收起状态下 0×0 的浮层，于是 Stack 自身也缩成 0×0，命中测试被裁掉。改为 `StackFit.expand`。
6. **修改昵称后弹窗报 "TextEditingController was used after being disposed"**：弹窗关闭动画期间仍在使用输入框，而控制器已被提前释放。改为由弹窗自己的 State 持有并释放控制器。
7. **绑定手机号成功后页面没有返回**：更新账号资料触发了路由刷新，与 `pop` 冲突。改为只在登录状态类别（已登录 / 未登录）变化时刷新路由。
8. **读屏无法激活侧栏入口**：端到端测试发现，`Semantics(excludeSemantics: true)` 丢掉了子组件的点击动作。在语义节点上补上 `onTap`，并增加回归测试。
9. **Android 构建报 "Could not close incremental caches"**：Pub 缓存（C 盘）和项目（D 盘）不在同一个磁盘时，Kotlin 增量编译缓存出错。在 `gradle.properties` 中关闭 `kotlin.incremental`。
10. **本机 6379 端口已被其他 Redis 占用**：开发 compose 的端口改为可通过 `.env` 中的 `POSTGRES_PORT` / `REDIS_PORT` 配置。

## 审查记录

### 服务端代码审查与安全审查（0 CRITICAL；HIGH 已全部修复）

| 发现 | 处理 |
|---|---|
| 刷新宽限期内的重试会让客户端持有的令牌失效（静默登出） | ✅ 改为幂等：缓存首次换发结果，并加密保存 |
| 设备下线依赖提交后再写 Redis，且 Redis 丢数据会让已下线的令牌恢复有效 | ✅ 改为由数据库 `tokens_valid_after` 判定（ADR-003） |
| 首次绑定手机号不需要重新验证身份，可被用来接管账号 | ✅ 绑定和换绑都需要当前密码 |
| 绑定手机号时的 `PHONE_TAKEN` 可以被用来探测已注册号码 | ✅ 先验证验证码，被占用的号码不发送验证码 |
| 登录锁定先读后写存在并发竞争，而且可以被用来锁住他人账号 | ✅ 改为原子的先计数，并分"账号+网络"和"账号"两级 |
| 单 IP 限额共用一个桶且计入成功请求，NAT 场景下会误伤用户 | ✅ 按接口分别计算并放宽，IPv6 按 /64 归并；生产环境必须配置可信代理 |
| 短信先占用号码冷却再查 IP 限额；验证码哈希可被穷举 | ✅ 调整为先查 IP；改用 HMAC |
| 升级密码哈希可能覆盖并发修改的新密码 | ✅ 更新时校验旧哈希 |
| 登录时密码长度按字节计算，中文长密码注册后无法登录 | ✅ 改为按字符计算，上限放宽到 128 |
| JWT `kid` 由密钥派生 | ✅ 去掉 `kid`，按密钥集合验签 |
| staging 可以使用示例密钥和模拟短信 | ✅ staging 与 production 同样禁止 |
| 推迟处理 | 找回密码时"已注册号码真正发送短信"带来的时间差（v0.9.0 接入真实通道时改为异步发送）；常见弱密码黑名单（v0.9.0） |

### 移动端审查（0 CRITICAL；HIGH 与 MEDIUM 已全部修复）

| 发现 | 处理 |
|---|---|
| **H** 隐私同意页不能滚动：横屏或大字号时"同意并继续"被截断，无法通过 | ✅ 新增 `JkFillScroll`（内容不足一屏时撑满，超出时可滚动），并加横屏 + 2 倍字号测试 |
| **H** 侧栏不能滚动：横屏或分屏时设置和帐号点不到 | ✅ 同上 |

| **H** 读取令牌抛出平台异常、或响应格式异常时，启动页卡住不动 | ✅ 恢复登录态时捕获所有异常，并落到确定的状态 |
| 刷新时临时失败（5xx、429）会被当作会话失效，把用户登出 | ✅ 只有服务端明确拒绝刷新令牌时才退出；其余情况使用缓存继续 |
| 刷新的边界情况 | ✅ 非网络异常不再逃逸；刷新期间退出登录时丢弃结果（登录态代次）；带旧令牌的 401 直接用新令牌重试，不再重复轮换；保存失败时保留在内存中 |
| 同意隐私政策之前就会恢复会话并发起网络请求 | ✅ 同意前不读取登录态，也不发请求，有测试覆盖 |
| 设置同步并发时较早的结果覆盖较新的修改；退出后下一个账号会上传上一个账号的未同步设置 | ✅ 同步串行执行，并用版本号保护；退出时清除"待同步"标记 |
| 浮层打开时读屏仍能访问下层内容；遮罩没有语义 | ✅ 用 `BlockSemantics` 屏蔽下层，遮罩标注为"关闭导航"按钮 |
| 平板和宽屏布局内容区缺少 SafeArea；收起浮层后第一次返回键无效 | ✅ 补上 SafeArea；动画状态变化时重建，旋转到宽屏时同步收起浮层 |
| 提交时遇到非接口异常没有提示 | ✅ 给出通用提示 |
| LOW（已修） | 图标栏点击区域 ≥ 48dp；加载中按钮带语义；验证码"发送中"状态在异常后能恢复；设备页内容不足一屏时也能下拉刷新，异步后检查 mounted；正式构建漏传 HTTPS API 地址时启动即报错 |
| LOW（推迟） | 2 倍字号下两段式切换按钮会略显拥挤，v0.3.0 统一调整组件尺寸；用 `MediaQuery.textScalerOf` 减少重建（收益很小） |
