# 2026-10-11 · v0.7.0 · M6 搜索与导出

## 目标

- **需求第 9 条**：全局搜索覆盖四个模块，也可以只搜某个模块，支持按时间、内容筛选。
- **需求第 8 条**：支持数据导出。

## 完成项

### 设计

见 [ADR-010](../架构/ADR/ADR-010-搜索与导出.md)：

- **搜索**：
  - 在本地建 FTS5 trigram 索引，中英文都能按任意片段匹配。
  - 不足 3 个字的关键词改用 LIKE。
  - 流水的索引只包含备注；关键词命中分类、账户或借贷对方时，在查询时带出引用它们的流水，改分类名后不用重建索引。
- **导出**：
  - 在服务端后台生成 zip，沿用备忘录提醒的做法，用 PostgreSQL 表领取任务，不引入 asynq。
  - 文件保留 24 小时，通过预签名链接下载，完成后推送通知。

### 移动端（`apps/mobile`）

- **搜索索引**：
  - 本地库升级到 v4，新增 `search_docs` 与外部内容 FTS5 表 `search_fts`，两者由触发器保持一致。
  - 每次保存记录时更新索引，覆盖本地编辑与同步下来的修改；删除记录时移除索引。
  - 升级时由已有记录分批重建索引，无法解析的记录跳过，不会让升级失败。
- **搜索**：
  - 多个关键词同时满足，最多 5 个。
  - 可按模块、日期区间筛选。
  - 结果按日期从新到旧，最多 200 条，按模块分组并显示各组条数。筛选在 SQL 中完成，只为前 200 条读取正文。
  - 片段与高亮在 Dart 中计算，长关键词和短关键词显示一致。
- **搜索页面**：
  - 窄屏从顶栏放大镜进入，宽屏从侧栏的"搜索"进入。
  - 在某个模块中打开时，默认只搜该模块。
  - 点击结果打开对应记录，返回后重新搜索。
- **数据导出页面**（设置 → 数据导出）：
  - 选择模块和是否包含附件，发起导出。
  - 有进行中的导出时，每 3 秒刷新一次状态。
  - 已完成的导出下载到临时目录后打开系统分享面板。本机只保留最近一次下载的文件，退出登录时删除。
  - 正式版只从 HTTPS 地址下载。
  - 删除导出前先确认。
- **通知渠道**：新增"其他通知"渠道，用于接收导出完成的推送。

### 服务端（`server`）

- **数据表**：新增 `exports` 表（迁移 00004），同一账号只能有一个进行中的导出（部分唯一索引）。用户删除的导出标为已删除并保留，仍计入次数。
- **后台任务**：
  - 用 `FOR UPDATE SKIP LOCKED` 领取任务，领取后独占 30 分钟。
  - 失败 1 分钟后重试，最多尝试 3 次。
  - 写入结果时核对尝试次数，过期的领取不会覆盖新的结果。
  - 服务停止时交还领取；生成中的 panic 按失败处理。
  - 没有记录指向的文件立即删除；启动时清理异常退出留下的临时文件。
- **生成导出文件**：
  - 按同步顺序分页读取并解密所选模块的记录（`syncer.EachRecord`），写入临时 zip 后上传到 `u/<用户>/exports/<任务>.zip`。
  - 注销账号时随附件前缀一起删除。
- **zip 的内容**：
  - `data.json`：所选模块的全部记录。
  - 工作日志：xlsx，以及每篇一个 Markdown 文件。
  - 笔记：按文件夹存放的 Markdown，开头为 YAML front matter；附件引用改写为相对路径。
  - 备忘录：ICS（带提醒，按 75 字节折行）和 CSV。
  - 记账：一个含四个工作表的 xlsx 和四个 CSV。金额在 xlsx 中是数字单元格，在 CSV 中写为两位小数。
  - 附件：选择包含附件时才有。
  - `README.txt`：文件说明，以及无法读取、未导出的记录数。
  - CSV 中以 `= + - @` 开头的文字前置单引号，防止公式注入。
- **接口**：
  - 发起、列表、状态、下载地址、删除，共五个接口。
  - 24 小时内最多导出 5 次。
- **清理与通知**：
  - 过期文件每 10 分钟清理一次，30 天前已结束的记录也一并删除。
  - 导出完成或失败时，向账号所有已登录的设备推送通知，内容不含数据。推送消息可以指定 Android 通知渠道。
  - 发起导出、获取下载地址、删除导出写入审计日志。
- **对象存储**：新增 `Open` 与 `PutFile`。
- **新依赖**：excelize v2.9.1。

## 关键决策

| 决策 | 理由 |
|---|---|
| 搜索索引放在本地，用外部内容 FTS5 表 | 服务端是密文，搜不了，而且离线也要能用。外部内容表加触发器后，按记录 ID 增删改只走普通表的唯一索引，不需要扫描全文索引 |
| 不足 3 个字时改用 LIKE | trigram 无法匹配不足 3 个字的词。1 万条记录时扫描一遍只要几十毫秒 |
| 分类、账户、借贷对方在查询时带出流水 | 索引只依赖单条记录，改名后不用重建流水的索引，也不受同步到达顺序的影响 |
| 片段与高亮在 Dart 中计算 | LIKE 查询用不了 FTS5 的 `snippet()`；两种查询应显示得一样 |
| 导出在服务端生成 | 本机不一定有全部附件，数据也可能尚未同步完整；手机上生成大文件既耗电又占空间 |
| 导出文件保留 24 小时，下载链接 10 分钟有效 | 导出文件是明文，留存时间越短越好 |
| 写入结果时核对尝试次数 | 领取过期后可能已被其他实例重新领取，以最新一次为准 |
| 导出完成时通知账号的所有设备 | 发起导出不需要再次验证身份；令牌被盗用时，用户能从其他设备上察觉 |

## 问题与解决

| 问题 | 解决 |
|---|---|
| 进行中的导出用转圈动画，组件测试的 `pumpAndSettle` 一直等不到结束 | 改用静态的沙漏图标。生成可能要几分钟，页面也不该一直重绘 |
| 设置页多了一项后，原有的"关于"测试点按落在屏幕外 | 测试中先滚动并重新布局，再点按 |
| 文件扩展名被当作文件名清理，开头的点被去掉 | 扩展名单独清理，再补上点 |
| 写 Go 文件时，`\u` 转义被工具替换成了实际字符（CSV 的 BOM） | 改用字节切片常量 |
| 设置页的"关于"测试中，滚动后立即点按，点按位置仍按滚动前计算 | 滚动后先重新布局再点按 |
| 提交命令中带 `grep -n`，被钩子误判为 `git commit -n` | 提交与其他命令分开执行 |

## 审查记录

三个审查（通用、Flutter、安全）都没有 CRITICAL。HIGH 与 MEDIUM 已修复并补了测试，部分 LOW 一并处理。

| 级别 | 问题 | 处理 |
|---|---|---|
| HIGH | 删除已完成的导出后，次数限制随之恢复，可以无限次导出 | 删除只删文件，记录标为已删除并保留，仍计入次数 |
| HIGH | 导出页面在请求返回前关闭时，仍然使用 `ref`，抛出未处理的异常 | await 之后先检查页面是否仍在；非接口错误也给出提示 |
| MEDIUM | 生成中账号被注销、写结果失败或最终失败时，上传的明文文件没有记录指向，永远不会被清理 | 这些情况下立即删除文件；启动时清理残留的临时文件 |
| MEDIUM | 无法解密的记录被静默跳过，导出仍显示完成 | 统计跳过的条数，写入 README |
| MEDIUM | 找不到的附件仍被链接到 zip 中不存在的文件 | 先复制附件，找不到的只写名称 |
| MEDIUM | 一个过期文件删除失败，会挡住后面所有过期文件的清理 | 记下错误继续处理 |
| MEDIUM（安全） | 发起导出不需要再次验证身份，没有审计记录，通知只发给发起的设备 | 完成通知发给所有设备，增加审计日志；二次验证记为已知限制，v0.9.0 再定 |
| MEDIUM | 本地库升级在一次读入全部记录的同时逐条解析，一条坏记录就会让升级失败、App 打不开 | 分批读取，跳过无法解析的记录 |
| MEDIUM | 短关键词命中很多时，把所有命中的正文读进内存后才截取 200 条 | 筛选放进 SQL，只为前 200 条读取正文 |
| MEDIUM | 深色模式下高亮文字对比度不足 4.5:1 | 改用 `onPrimaryContainer` |
| MEDIUM | 导出列表定时刷新偶尔失败时，整个列表变成错误页 | 有数据时保留列表 |
| MEDIUM | 搜索结果每次重建都重新生成名称表、构建全部条目 | 名称表放进 provider，结果列表按需构建 |
| MEDIUM | 备忘录的索引日期与导出中全天备忘的日期都依赖时区 | 写入 ADR 的已知限制 |
| LOW（一并处理） | CSV 公式注入；错误日志中带文件名；生成中 panic 会让服务退出；服务停止时浪费一次尝试；IN 列表可能超过变量上限；本机导出文件退出登录后仍在；没有限制只从 HTTPS 下载；Windows 保留文件名；高亮只折叠 ASCII 大小写；清除按钮不及时出现 | 全部修复 |

## 遗留事项与下一步

- 导出时整个账号的所选记录一次读入内存。文本记录一般只有几 MB；附件以流的方式复制，不受影响。数据量很大时可以改为分模块读取。
- 发起导出暂不需要再次验证身份，v0.9.0 安全审查时再定。
- v0.9.0 部署时在对象存储上为 `u/*/exports/` 配置 2 天的生命周期规则，作为清理的兜底。
- **需要真机验收**：
  - 搜索：顶栏入口、中文短词、模块筛选与时间筛选。
  - 导出：通知、下载后的分享面板，以及在电脑上打开 xlsx、ics 和 Markdown 文件。
