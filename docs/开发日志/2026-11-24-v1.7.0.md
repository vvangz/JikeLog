# 2026-11-24 · v1.7.0 · 群青主题视觉焕新与应用内自动更新

## 目标

1. 告别原有的咖色/奶油白视觉体系，重新设计全端深浅主题色板与应用图标，保持高对比度（WCAG 2.2）与清爽现代质感。
2. 为 Android 与 Windows 客户端提供应用内覆盖更新能力，无需用户每次手动访问官网下载安装包。

### 应用内覆盖更新（Android APK & Windows MSIX）

- **复用同源清单与 CA 锁定**：直接请求同源 `https://www.pingvv.top/download/latest.json` 与 `/download/<installer>`，复用 `tlsPolicyProvider`（正式版锁定 Let's Encrypt 根证书）。
- **严格校验与缓存复用**（`features/update/`）：
  - 严格校验 SemVer 版本、单段安全文件名（`.apk`/`.msix`）、大小上限（512 MiB）与 64 位 SHA-256；
  - 流式下载至 `.part` 临时文件并逐字节校验 SHA-256，校验通过后再原子重命名；校验失败立即删除；
  - 本地已有校验通过的同版本包时直接复用，避免授权或重试时重复下载；
  - Android 写入应用缓存目录 `cacheDir/jikelog-update/`；Windows 写入用户下载目录下的 `JikeLog-Updates/`（避开 MSIX 虚拟化 Temp 路径导致外部 `AppInstaller.exe` 无法读取的问题）。
- **平台覆盖安装**：
  - **Android**：声明 `REQUEST_INSTALL_PACKAGES` 权限与仅暴露 `jikelog-update/` 子目录的独立 `FileProvider`（`${applicationId}.update.fileprovider`），在 `MainActivity.kt` 提供 `jikelog/updater` 通道（含规范路径前缀纵深校验）；未开启「允许来自此来源的应用」时引导前往系统授权页，返回后点击「继续安装」直接复用已校验 APK 覆盖安装。
  - **Windows**：通过系统默认关联拉起 Windows 应用安装程序打开已校验 `.msix`，直接覆盖更新并保留全部本机数据。
- **交互入口**：概览页启动静默检查一次（离线静默忽略，发现新版展示可忽略的顶部横幅），并在 **设置 → 检查更新** 与 **关于 → 检查更新** 提供随时手动检查、进度条、取消/重试与更新日志跳转。
