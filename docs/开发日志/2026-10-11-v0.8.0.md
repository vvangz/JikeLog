# 2026-10-11 · v0.8.0 · M7 Web 管理后台

## 目标

需求第 1 条：管理员只能查看用户的一些配置信息。

实施计划 3.10 节规定了以下内容：

- **页面**：
  - 登录
  - 仪表盘
  - 用户列表（手机号脱敏）
  - 用户详情（只显示配置）
  - 审计日志
  - 管理员管理
- **隔离**：管理员令牌访问任何内容接口都必须返回 403。
- **外壳**：与移动端一致。

## 完成项

### 设计

见 [ADR-011](../架构/ADR/ADR-011-管理后台.md)：

- **独立的管理员身份**：管理员使用单独的 `admin_users` 表，角色分为超级管理员和只读管理员。第一个超级管理员用命令行创建。
- **会话**：
  - Access Token 的有效期为 15 分钟，受众为 `admin`，签名密钥由 JWT 密钥派生，与用户令牌的密钥不同。
  - Refresh Token 放在 HttpOnly Cookie 中（`SameSite=Strict`），刷新和退出时要求带自定义请求头。
- **隔离**：认证按路由前缀分流。管理员令牌访问用户接口一律返回 403 `ADMIN_FORBIDDEN`。
- **审计**：所有查看与管理操作都写入审计日志，写入失败时拒绝请求。

### 服务端（`server`）

- **迁移 00005**：新增 `admin_users`、`admin_sessions`、`admin_audit_logs` 三张表，并为统计查询加了索引。
- **13 个管理接口**：
  - 登录、刷新、退出
  - 当前管理员、修改密码
  - 仪表盘
  - 用户列表、用户详情
  - 审计日志
  - 管理员的列表、新建、修改和重置密码
- **登录防护**（计数放在 Redis）：
  - 同一用户名从同一 IP 15 分钟内失败 5 次，锁定到窗口结束。
  - 同一用户名每小时最多失败 30 次。
  - 同一 IP 每 15 分钟最多尝试 20 次。
  - 用户名存在与否，响应和耗时都相同。
  - 首次登录或被重置密码后，必须先修改密码。
- **会话**：
  - Refresh Token 每次刷新都轮换，会话最长 12 小时。
  - 轮换后 10 秒内，旧令牌仍可换取 Access Token；超过 10 秒旧令牌再次出现，视为被盗用，撤销整个会话。
  - 修改或重置密码、停用账号时，相关会话立即失效。
- **用户数据只读且最少**：
  - 列表中手机号脱敏，并且只能按手机号末 4 位搜索。
  - 用户详情只包含：设置；设备的平台、型号、版本、最后活跃，以及是否已同步到最新；最后同步时间；附件用量。
- **至少保留一个启用的超级管理员**：修改角色或停用时串行执行，并在事务内复核调用者。
- **新增命令 `jikelog-admin`**：
  - 用于创建管理员、重置密码，密码从标准输入读取。
  - 已打包进服务端镜像。

### 管理后台（`apps/admin-web`）

- **技术**：React 19、Ant Design 6、React Router 8、TanStack Query 5、openapi-fetch，类型由 OpenAPI 生成。
- **会话**：
  - Access Token 只在内存中。
  - 打开页面时用 Cookie 恢复登录。
  - 接口返回 401 时自动刷新并重试；多个请求同时过期时只刷新一次。
  - 退出或会话失效时清空缓存的数据。
  - 连不上服务器时显示可重试的状态，不当作已退出。
- **外壳**：
  - 左上角入口图标展开侧栏，上方是仪表盘、用户、审计日志，下方是管理员、设置、账号。
  - 宽屏时侧栏常驻；窄屏时侧栏为抽屉，有遮罩，可用 Esc 关闭，焦点留在浮层内。
  - 支持浅色、深色和跟随系统。
- **页面**：
  - 仪表盘：统计卡片、近 30 天每日新增的柱状图、平台分布。
  - 用户：可搜索、分页，状态保存在地址中。
  - 用户详情。
  - 审计日志：可按操作和日期筛选。
  - 管理员：新建、修改角色、停用、重置密码。
  - 设置、账号（修改密码、退出）。
- **安全**：内容安全策略只允许同源资源，首屏主题的内联脚本按哈希放行，测试会校验哈希。
- **测试**：
  - Vitest 单元测试，与端到端测试共用同一个内存中的模拟接口。
  - Playwright 端到端测试，已加入 CI。

## 关键决策

| 决策 | 理由 |
|---|---|
| 管理员是独立的账号体系，令牌的受众和签名密钥都与用户不同 | 管理员不能登录 App；即使某处受众校验写错，两种令牌也不能互用 |
| 认证按路由前缀分流，用户接口识别出管理员令牌时返回 403 | 隔离由中间件统一保证，新增的用户接口自动受保护；测试逐一检查全部用户路由 |
| Refresh Token 放在 HttpOnly Cookie，Access Token 只在内存 | 页面存在 XSS 时也偷不到长期有效的令牌 |
| 查看操作先写审计再返回数据 | "所有查看都有记录"不能因为审计写入失败而落空 |
| 登录失败按"用户名 + IP"计数，另设按用户名的总上限 | 既防猜密码，又不能借锁定判断用户名是否存在，也不容易被别人恶意锁住 |
| 只能按手机号末 4 位搜索 | 更长的号码片段可以逐位试出完整手机号 |
| 端到端测试在浏览器层模拟接口 | CI 不需要起数据库和对象存储；服务端接口由 Go 集成测试覆盖 |

## 问题与解决

| 问题 | 解决 |
|---|---|
| React 规范检查报告在渲染中读取 ref、在 effect 中同步设置状态 | 令牌改放在客户端工厂的闭包里；媒体查询改用 `useSyncExternalStore`；宽窄屏各自保存侧栏的展开状态 |
| jsdom 没有 `ResizeObserver`，Ant Design 的表格和菜单报错 | 在测试初始化中补一个空实现 |
| Ant Design 会在两个汉字的按钮中间加空格（"登 录"） | 测试中用允许空格的正则匹配按钮名 |
| 同一页面上两个表单都有 `password` 字段，标签指向错误 | 给表单设置 `name`，字段 ID 带上前缀 |
| 侧栏改成 sticky 后，Playwright 滚动页面时侧栏跟着移动，点击一直等不到稳定位置 | 整页固定为视口高度，侧栏与内容区各自滚动 |
| CSP 禁止了首屏主题的内联脚本 | 按脚本的 SHA-256 放行，并加测试保证二者一致 |
| 统计查询中 `max()` 可能为空，扫描进非空字段时出错 | 用 `COALESCE`，或改为 `ORDER BY … LIMIT 1` 在查不到时单独处理 |

## 审查记录

三个审查（通用、安全、TypeScript）都没有 CRITICAL。HIGH 与 MEDIUM 已修复并补了测试，大部分 LOW 一并处理。

| 级别 | 问题 | 处理 |
|---|---|---|
| HIGH（通用、安全） | User-Agent 中的非法 UTF-8 或 NUL 会让审计写入失败，而查看照常返回数据：可以不留痕迹地查看用户 | 清理来自请求的字符串；查看与管理操作写审计失败时拒绝请求 |
| HIGH（通用） | 两个超级管理员同时互相降级，可能一个超级管理员都不剩 | 修改角色与停用串行执行，并在事务内复核调用者 |
| HIGH（TypeScript） | 退出或会话失效后，页面缓存的数据还在，下一位登录的管理员会短暂看到 | 退出、会话失效与登录时清空缓存 |
| HIGH（TypeScript） | 退出请求失败时也回到了登录页，但 Cookie 仍有效，刷新页面又自动登录 | 退出失败时提示并留在原页面 |
| MEDIUM | 锁定只发生在存在的用户名上，可以借此判断用户名是否存在；知道用户名的人可以一直把管理员锁住 | 按"用户名 + IP"计数，另设按用户名的总上限，用户名存在与否表现一致 |
| MEDIUM（安全） | 手机号可以按任意长度的末尾搜索，逐位试出完整号码 | 只接受恰好 4 位 |
| MEDIUM（安全） | 查看审计日志与管理员列表没有审计 | 新增两种审计操作 |
| MEDIUM | 多个标签页同时刷新时，后到的那个被登出 | 服务端旧令牌保留 10 秒宽限，宽限后重用则撤销会话 |
| MEDIUM | 刷新时的网络错误或 5xx 被当作已退出 | 只有 401/403 才退出；启动时连不上服务器显示可重试的状态 |
| MEDIUM | 多个请求同时 401 时会多次刷新；退出后迟到的刷新结果把会话恢复回来 | 按令牌是否已更新决定是否刷新；用会话代次丢弃迟到的结果 |
| MEDIUM | dummy 哈希可能因首个请求被取消而永久为空，计时差异又出现了 | 不再依赖请求上下文 |
| MEDIUM | 最后同步时间的查询没有索引 | 改按同步序号查询 |
| MEDIUM（TypeScript） | 窄屏侧栏不能用键盘关闭，焦点会落到遮罩后面；页面很长时下方的入口要滚到底 | 窄屏改用抽屉；整页固定高度 |
| MEDIUM（TypeScript） | 只读管理员打开管理员页时仍发请求；用户搜索框与地址不同步；页码未校验；网络错误提示不准确 | 全部修复 |
| LOW（一并处理） | 登录输入长度未校验；修改密码时可以无限次猜当前密码；审计不记修改前的值；命令行操作没有审计；详情与列表的最后活跃不一致；返回按钮在新标签页中无效；静态页面没有 CSP；Playwright 未设 `forbidOnly` | 全部修复 |
