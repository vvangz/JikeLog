# 2026-10-27 · v1.5.0 · 概览首页

## 目标

此前登录后直接进入工作日志：新用户看到的是空状态，老用户只看到一个模块，没有跨模块的全局视图。本版新增"概览"作为默认首页，汇总四个模块的关键统计与近期内容，要求美观高级。

与用户确认的做法：

- 概览作为**默认首页**，并放在侧栏**四个模块之上**。
- 记账金额**默认显示**，卡片右上角的眼睛按钮可切换为 `****`，选择**记在本机**。
- 视觉沿用现有的**奶油白 / 深咖**设计令牌：顶部深咖渐变主卡，下方细边白卡片，Space Grotesk 大号数字。
- 在各模块页按**返回键回到概览**，只有在概览页才退出 App。

全部数据来自本机已有的 drift 数据流（离线可用、实时更新），服务端没有改动。

## 完成项

### 页面

- **顶部主卡**：日期、按时段的问候语（早上好 / 中午好 / 下午好 / 晚上好）+ 昵称、今日摘要（备忘待完成与逾期条数、今日日志是否已写）。四个半透明快捷按钮复用各模块已有的新建入口：`createWorklog`、`createNote`、`createMemo`、`/ledger/entry/new`。浅色主题用 `primary → onPrimaryContainer` 渐变，深色主题用 `primaryContainer → surfaceVariant`，右上角有淡淡的同心圆装饰。
- **工作日志卡**：连续记录天数（今天没写时从昨天起算）、本月篇数、今日是否已写，以及按天的记录热力图。热力图用 CustomPaint 绘制，格子大小由高度决定，按可用宽度显示最近若干周，计数分 4 档深浅。周起始日跟随"一周的第一天"设置。
- **备忘录卡**：今日待办、已逾期（之前日期未完成）、本周完成率圆环，以及接下来 3 条未完成、未过时的备忘（"今天 14:00 / 明天 全天 / 11月3日 08:00"）。
- **记账卡**：本月支出、收入、结余，近 30 天每日支出迷你曲线（fl_chart 面积渐变，不显示坐标轴），以及净资产。全部复用 `ledger_stats.dart` 的 `periodTotals`、`netWorth`、`trend`。眼睛按钮切换隐藏，读屏时报"已隐藏"。
- **笔记卡**：总数、近 7 天编辑篇数、收藏数，以及最近编辑的 3 篇（相对时间）。
- **布局**：内容宽度小于 600 时单列；不小于 600 时两列，同一行的卡片用 `IntrinsicHeight` 等高；内容最大宽度 1040，居中显示。卡片内部不能用 `LayoutBuilder`，热力图因此靠固定高度推算列数，宽屏两列时加大高度以填满卡片。
- **动效**：数字从 0 滚动到目标值，卡片依次淡入上移；系统开启"减少动态效果"时都不播放。
- 每张卡片各自处理加载中、出错与空数据。新用户看到的是一句引导和全零的统计，不会是空白。下拉刷新触发同步。

### 导航

- 新增 `overviewDestination`（`/overview`）和 `JkIcons.overview` 图标（四个大小不一的圆角块）。概览只出现在 `allDestinations` 与侧栏中，不加入 `moduleDestinations`，因此不影响模块路由、Ctrl+N 和搜索范围：在概览页按 Ctrl+F 搜索全部内容，按 Ctrl+N 不响应。
- `homePath` 由 `/worklog` 改为 `/overview`。
- `AppShell` 的返回键处理：侧栏浮层打开时先收起浮层；在概览以外的外壳页面（模块、设置、帐号）回到概览；只有在概览页才交给系统，即退出 App。全屏子页面仍先返回上一级。

### 统计（`features/overview/overview_stats.dart`）

纯函数，便于测试：`weekStartOf`、`worklogSummary`、`memoSummary`、`noteSummary`、`greetingFor`、`relativeTime`。日期推算一律使用 `DateTime(y, m, d ± n)`，跨夏令时也不会出错。记账概况 `ledgerSummary` 放在 `overview_providers.dart` 中。

各概况 Provider 都是 `autoDispose` 的：离开概览后释放，回来时按当前时间重新计算。页面一直开着时，App 回到前台会刷新，跨过零点时也由计时器刷新。

## 问题与解决

| 问题 | 原因 | 解决 |
|---|---|---|
| 原有的大字号测试在概览上溢出 | 2 倍字号时，大号数字与小指标挤在同一行 | 小指标改为放不下时自动换行，单位文字可收缩 |
| 手机上备忘卡的两个大数字上下排列 | 数字与单位所在的 `Row` 默认占满宽度，`Wrap` 中每项都独占一行 | 改为 `mainAxisSize: min` |
| 宽屏下工作日志卡底部大片留白 | 热力图高度固定，比同一行的备忘录卡矮 | 两列布局时加大热力图高度 |
| 页面开着过夜后统计仍是昨天的（审查发现） | 概况只在数据变化或重新进入页面时计算 | 回到前台与零点时刷新 |
| 隐藏金额的设置保存失败时界面与存储不一致（审查发现） | 先改状态、后写存储，失败时没有处理 | 失败时恢复原状并记日志 |
| 原有测试默认登录后停在工作日志 | 首页改成了概览 | `pumpApp` 新增 `path` 参数与 `goTo` 辅助函数，相关测试先转到 `/worklog` |
