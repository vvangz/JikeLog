# ADR-002 字体文件不入库，由脚本下载

- 状态：已采纳
- 日期：2026-10-08

## 背景

需求指定字体为 Space Grotesk + MiSans，而仓库是公开的。核对小米官方《MiSans 字体知识产权许可协议》（hyperos.mi.com/font）后，相关条款如下：

1. 应在软件中特别注明使用了 MiSans 字体；
2. 不得对 MiSans 字体或其任何单独组件进行改编或二次开发；
3. 不得单独将 MiSans 字体或其组件对外……分发字体软件或其任何副本以及重新分发或售卖；但这一限制不适用于使用 MiSans 创作的其他作品（如应用 App），这类作品可以分发或出售。

因此，把字体打包进 App 是允许的，但把 TTF 文件放进公开仓库属于"单独分发字体副本"，不被允许。

## 决策

- `apps/mobile/assets/fonts/` 和 `apps/admin-web/public/fonts/` 已加入 `.gitignore`
- `scripts/fetch-fonts.sh` 从官方渠道下载：Space Grotesk 2.0.0（GitHub Release，OFL 1.1），以及 MiSans（`https://hyperos.mi.com/font-download/MiSans.zip`）
- 移动端只打包 MiSans Regular/Semibold 和 Space Grotesk Regular/Medium/Bold，用来控制 APK 体积（MiSans 每个字重约 8MB）
- CI 用 `actions/cache` 缓存下载结果
- App 的"关于"页和 README 都会注明使用了 MiSans 字体（v0.2.0 实现"关于"页）
- 不对 MiSans 做子集化以外的修改。Web 端在 v0.8.0 按 unicode-range 切片加载：切片只改变文件组织方式，不改变字形外观，上线前会再次确认是否符合许可

## 影响

- 新成员克隆仓库后需要先执行 `bash scripts/fetch-fonts.sh`，否则 Flutter 构建会因为找不到字体资源而失败
- 如果小米调整了下载地址，需要更新脚本中的 URL
