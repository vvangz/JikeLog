# 架构决策记录（ADR）

每个影响面较大、事后难以撤销的决策都记一条 ADR，模板如下：

```
# ADR-XXX 标题
- 状态：提议 / 已采纳 / 已废弃（被 ADR-YYY 取代）
- 日期：YYYY-MM-DD
## 背景
## 决策
## 备选方案
## 影响
```
