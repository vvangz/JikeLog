# 即刻日志隐私政策

更新日期：2026 年 10 月 23 日

生效日期：2026 年 10 月 24 日

即刻日志（以下简称"我们"）由张旺运营，提供工作日志、笔记、备忘录与记账服务，包括 Android 版、Windows 版与本网站。本政策说明我们如何处理你的个人信息。请在使用前仔细阅读，尤其是加粗的内容。

## 1. 我们收集的信息

我们只收集提供服务所必需的信息。

| 场景 | 信息 | 用途 |
|---|---|---|
| 注册与登录 | 用户名、昵称、密码 | 创建和识别账号。**密码只保存不可逆的哈希值（argon2id）**，我们无法得知你的密码 |
| 绑定手机号（可选） | 手机号 | 验证码登录、找回密码、注销时验证身份。服务器开通短信服务后才可使用；后台只显示脱敏后的号码 |
| 登录设备 | 设备平台、型号（Windows 上统一记为"Windows PC"，不读取计算机名）、系统版本、应用版本、应用安装标识、最近活跃时间与 IP 地址 | 在"登录设备"中显示、下线指定设备，识别异常登录 |
| 你记录的内容 | 工作日志、笔记、备忘录、账目，附件的文件名、类型、大小与文件本身，以及修订历史 | 存储与多设备同步 |
| 设置 | 主题、字号、默认提醒、每周起始日 | 在你的各台设备上保持一致 |
| 服务器日志 | IP 地址、请求的接口、响应状态与时间 | 排查故障、防范攻击。**日志不记录请求内容**，按大小滚动覆盖 |

我们不收集你的位置信息、通讯录、已安装应用列表或设备的电话信息，也不在应用中投放广告或接入统计分析服务。

## 2. 系统权限

以下权限只在使用相应功能时请求，可随时在系统设置中关闭，关闭后不影响其他功能。

| 权限 | 平台 | 用途 |
|---|---|---|
| 网络 | 全部 | 登录与同步 |
| 通知、精确闹钟、开机启动 | Android | 在备忘时间到达时提醒你；重启手机后恢复已排定的提醒 |
| 通知 | Windows | 在备忘时间到达时弹出 Windows 通知 |
| 日历（读写） | Android | 仅在你于"设置"中开启"备忘录同步到系统日历"时请求，见第 4.4 节 |
| 麦克风 | 全部 | 仅在你为笔记录音时请求 |
| 文件与相册 | 全部 | 通过系统的文件选择器选取附件，我们只读取你选中的文件 |

## 3. 我们如何使用信息

1. 提供登录、同步、提醒、搜索与导出等功能。
2. 保障账号安全：限制频繁的登录与验证请求，识别异常登录。
3. 管理员通过管理后台只能查看账号的配置信息：用户名、昵称、脱敏手机号、设置、登录设备、同步状态与存储用量，**看不到你记录的任何内容**。管理员的每次查看都记入审计日志。

我们不会出售你的个人信息，也不会把你的记录用于广告或模型训练。

## 4. 信息的存储与保护

### 4.1 存储地点

数据存储在位于**中国境内**的云服务器上（阿里云），不会传输到境外。

### 4.2 加密

- **传输**：全程使用 HTTPS。工作日志、笔记、备忘录与账目的文字内容（如日志的地点和正文、笔记的标题、正文和标签、备忘内容、账户名称与金额）以及附件的文件名，在 HTTPS 之上再用 X25519 + AES-256-GCM 加密一次。
- **存储**：上述内容在服务器上以每个账号独立的密钥加密保存。
- **不加密的部分**：日期、备忘的提醒时间等需要服务器据此排序和提醒的字段，附件的类型和大小，以及**附件文件本身**，在服务器上不做应用层加密。附件只能通过登录后获取的签名地址上传和下载，地址分别在 15 分钟、10 分钟后失效。
- **加密的边界**：服务器需要解密后才能合并多台设备的修改、生成导出文件，因此运营者在技术上能够解密你的记录。我们通过访问控制、审计日志与操作规范限制这一能力，承诺不会查看你的记录内容，除非法律法规要求。

### 4.3 备份

服务器每 14 天做一次全量备份，备份用公钥加密后保存到异地的对象存储（阿里云，上海），保留最近 6 份（约 84 天）。只有运营者持有解密备份所需的私钥。

### 4.4 保存在你设备上的信息

- 你的记录会缓存在设备上，以便离线使用。请为设备设置锁屏密码。
- 开启"同步到系统日历"后，每条备忘的第一行和时间以明文写入本机名为"即刻日志"的日历，**获得日历权限的其他应用可以读取**。关闭该选项会删除这个日历。
- 提醒通知的标题是备忘的第一行；Android 锁屏时显示"内容已隐藏"。
- 导出的文件保存在你选择的位置；服务器上的导出文件在生成 24 小时后自动删除。

## 5. 保存期限

- 账号存续期间，我们保存你的账号信息和记录。
- 你删除一条记录后，服务器保留一个"已删除"标记，以便其他设备同步删除；**删除前的最后版本以加密形式保存在修订历史中**，误删时可以恢复。被删除的附件文件会由服务器定期清除。如需从服务器彻底清除全部记录，请注销账号。
- **注销账号后，账号与全部记录立即从服务器的数据库中删除**，附件文件随后由服务器清除，所有设备下线，无法恢复。此前生成的备份中仍有这些数据的加密副本，会在最多约 84 天内随备份轮换删除；在此之前，持有备份私钥的运营者在技术上仍能从备份中恢复它们，我们只在灾难恢复时使用备份。
- 服务器日志按大小滚动覆盖，通常保留不超过数周。

## 6. 第三方服务

当前版本**没有启用任何第三方 SDK**。Android 安装包中包含极光推送 SDK，但未配置、不会初始化，不收集任何信息。将来启用推送或短信服务前，我们会更新本政策并请你重新确认。

我们使用以下服务商提供基础设施，它们只按我们的指示处理数据：

| 服务商 | 用途 |
|---|---|
| 阿里云计算有限公司 | 服务器与备份存储 |
| GitHub, Inc. | 托管源代码；安装包的备用下载地址（只在你选择从 GitHub 下载时访问） |

## 7. 你的权利

- **查阅与更正**：在"帐号"中查看和修改昵称、手机号与密码，查看并下线登录设备。
- **复制**：随时在"导出"中导出全部数据。
- **删除**：删除任意记录；或在"帐号"中注销账号，删除全部数据。
- **撤回同意**：可随时关闭系统权限。撤回对本政策的同意需要停止使用并注销账号。
- **联系我们**：对个人信息处理有疑问、意见或投诉，按第 10 节的方式联系我们，我们会在 15 个工作日内答复。
