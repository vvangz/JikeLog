# 07 记账

> 适用版本：v0.6.0 及以上

记账用来记录每一笔收入、支出、转账和借贷，并统计分类占比、收支趋势、账户余额和净资产。金额、账户名、分类名、借贷对方和备注都在传输和存储时加密，统计全部在手机上计算。

从 **导航栏 → 记账** 进入。顶部有三个页签：**流水**、**统计**、**账户**。

## 1. 开始之前：添加账户

记账前至少要有一个账户。在 **账户** 页签点击 **添加账户**，填写：

- **名称**：如"招商银行储蓄卡"、"零钱"，最多 30 字。
- **类型**：现金、储蓄卡、信用卡、支付宝、微信、其他。
- **初始余额**：开始记账时这个账户里的钱，单位为元，最多两位小数。**信用卡的欠款填负数**，例如 `-1200`。

第一次打开记账时，App 会自动准备一套常用的收支分类，例如餐饮（早餐、午餐、晚餐、零食饮料）、交通、购物、居住、工资、奖金。你可以修改它们，见第 6 节。

## 2. 记一笔

点击右下角的 **记一笔**，先在顶部选择类型：

| 类型 | 需要填写 | 对余额的影响 |
|---|---|---|
| 支出 | 金额、账户、分类 | 账户减少 |
| 收入 | 金额、账户、分类 | 账户增加 |
| 转账 | 金额、转出账户、转入账户，手续费可不填 | 转出账户减少金额与手续费，转入账户增加金额；手续费计入支出（"手续费"分类） |
| 借贷 → 借出 | 金额、账户、借给谁，到期日可不填 | 账户减少，待收增加 |
| 借贷 → 借入 | 金额、账户、向谁借，到期日可不填 | 账户增加，待还增加 |
| 借贷 → 收款 | 金额、账户、收回哪笔借出 | 账户增加，待收减少 |
| 借贷 → 还款 | 金额、账户、归还哪笔借入 | 账户减少，待还减少 |

- 金额最多两位小数。
- 分类先点选一级分类；有二级分类的会在下方列出，可以再选一个更具体的，也可以不选。
- 日期默认是今天，点击可以修改。
- 备注可不填，最多 1000 字。
- 账户默认选中上次使用的账户。
- 点击 **保存** 后返回。漏填或填错时，保存按钮上方会提示原因。

## 3. 流水

- 按月查看，点击月份两侧的箭头切换。
- 顶部显示本月的 **收入**、**支出**（含转账手续费）和 **结余**。
- 流水按日期分组，每天的标题右侧显示当天的收入与支出合计。
- 每条流水显示：
  - **分类**：二级分类显示为"餐饮 · 午餐"。转账显示为"转出账户 → 转入账户"，借贷显示为"借出 · 李四"。
  - **备注和账户**。
  - **金额**：增加余额的带"+"，减少余额的带"-"。
- 点击流水可以修改或删除。删除后账户余额和统计随之更新，其他设备上也会删除。
- 在列表中向下拉，可以立即同步一次。

## 4. 统计

- 选择 **月** 或 **年**，用箭头切换时间。
- 顶部是这段时间的收入、支出和结余。
- **支出构成 / 收入构成**：
  - 饼图显示各一级分类的占比，最多单独显示 7 个分类，其余合并。
  - 下方的排行列出每个分类的金额、占比和笔数。
  - 有二级分类的一级分类，点击可以查看其下二级分类的明细。点击"返回"回到一级分类。
- **收支趋势**：月视图按日、年视图按月显示，绿色柱为收入，咖色柱为支出。

## 5. 账户与借贷

**账户** 页签：

- **净资产** = 各账户余额之和 + 待收 − 待还，下方分别列出这三项。
- 每个账户显示当前余额（初始余额加上所有流水的影响），欠款显示为负数。
- 点击账户可以修改名称、类型和初始余额，也可以隐藏或删除：
  - **已有流水的账户不能删除**，只能隐藏。隐藏后不再出现在记账的选择列表中，历史流水和余额照常显示。
  - 没有流水的账户可以直接删除。
  - 隐藏的账户列在"已隐藏的账户"中，点击可以取消隐藏。
- **借贷** 列出每一笔借出和借入，显示待收或待还的金额与到期日。过了到期日还没结清的显示"已逾期"。

点击一笔借贷进入详情，可以：

- 查看借出（借入）总额、已收（已还）和待收（待还），以及相关的全部流水。
- 点击右下角的 **记一笔收款 / 还款**，直接记录这笔借贷的收回或归还。
- 修改对方、设置或清除到期日。
- 打开 **已结清**：全部收回或还清后标记，借贷移到"已结清"中。
- **删除**：这笔借贷的借出、借入、收款、还款流水会一并删除。

## 6. 管理分类

在 **账户** 页签底部点击 **管理收支分类**，或在记一笔时点击分类旁的 **管理**。

- 切换 **支出 / 收入** 查看两类分类。
- 点击右下角的 **新增分类** 添加一级分类，点击某个一级分类下方的"在…下新增"添加二级分类。名称最多 20 字，可以选择图标。
- 点击分类可以改名、换图标、隐藏或删除：
  - **预置分类**和**已有流水的分类**只能隐藏，不能删除。隐藏后不再出现在选择列表中，历史流水和统计照常显示。
  - 隐藏一级分类时，它的二级分类一并隐藏。

## 7. 多设备与数据安全

- 记账数据与其他内容一样在你的设备之间同步，见 [04 多设备同步](04-多设备同步.md)。
- 两台设备同时修改同一条流水时，同一项以后修改的为准，不同项都会保留。
- 预置分类在每台设备上的 ID 相同，多台设备同时初次使用记账也不会出现两份。
- 在任何一台设备上修改过的预置分类，不会被其他设备的默认名称覆盖。
- 金额、账户名、分类名、借贷对方和备注在服务器上加密存储，管理员和服务器都无法查看。
