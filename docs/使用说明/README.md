| [03 工作日志](03-工作日志.md) | 新建、编辑、自动保存、Markdown、附件、修订历史 | v0.3.0 |
| [04 多设备同步](04-多设备同步.md) | 同步时机与状态、离线使用、冲突合并规则、退出与切换账号 | v0.3.0 |
| [05 笔记](05-笔记.md) | 富文本 / Markdown、代码块、表格、待办、文件夹、标签、收藏、附件、录音、关联工作日志 | v0.4.0 |
| 06 备忘录 | 提醒设置、日历视图、同步到系统日历、通知权限 | v0.5.0 |
| 07 记账 | 账户、分类、收支、转账、借贷、统计图表 | v0.6.0 |
| 08 搜索与导出 | 全局搜索、筛选、导出格式说明 | v0.7.0 |
| 09 常见问题 | 收不到提醒、同步失败、数据安全 | v0.9.0 |
