# 05 笔记

> 适用版本：v0.4.0 及以上

笔记用来记录会议纪要、方案、学习资料等。支持富文本和 Markdown 两种编辑方式，可以插入代码块、表格、待办清单、图片，用文件夹、标签和收藏整理，还能关联到工作日志。笔记会自动保存，并同步到你登录的其他设备。

## 1. 笔记列表

从 **导航栏 → 笔记** 进入。

- 笔记按最后修改时间倒序排列，**置顶**的笔记排在最前面（标题前有图钉图标）。
- 每篇笔记显示标题、正文摘要、修改时间、所在文件夹、标签（最多 3 个）和关联的工作日志数量。没有标题时用正文的第一行作为标题。
- 标题右侧的星标表示已收藏；同步状态图标与工作日志相同（见 [03 工作日志](03-工作日志.md) 第 1 节）。
- 在列表中向下拉，可以立即同步一次。

### 筛选

点击列表上方的 **文件夹与标签**（平板等宽屏上，筛选面板固定显示在左侧），可以选择：

| 选项 | 显示 |
|---|---|
| 全部笔记 | 所有笔记 |
| 收藏 | 收藏的笔记 |
| 未分类 | 没有放进文件夹的笔记 |
| 某个文件夹 | 该文件夹及其子文件夹中的笔记 |
| 某个标签 | 带有该标签的笔记 |

每一项右侧的数字是其中的笔记数量。列表上方显示当前的筛选条件，例如"工作 / 项目 A"或"#周报"。

## 2. 新建笔记

点击右下角的 **新建笔记**，默认用富文本方式编辑。

- 当前筛选的是某个文件夹时，新笔记放进这个文件夹；筛选的是某个标签时，新笔记自动带上这个标签；筛选的是收藏时，新笔记自动收藏。
- 输入标题（最多 200 字）和正文（最多 10 万字）。**不需要点保存**：停止输入 1 秒后自动保存，离开页面时也会立即保存。
- 顶部标题下方显示同步状态，含义与工作日志相同。

## 3. 两种编辑方式

点击顶部的 **切换** 按钮（"Tt" 或 "</>" 图标）可以随时在两种方式之间切换，内容不会丢失。每篇笔记会记住上次使用的方式。

### 富文本

所见即所得。底部工具栏：

| 按钮 | 效果 |
|---|---|
| 撤销 / 重做 | 撤销或恢复上一步编辑 |
| 标题 | 一级、二级、三级标题，或恢复为正文 |
| 加粗、斜体、删除线、行内代码 | 作用于选中的文字；没有选中时作用于接下来输入的文字 |
| 待办 | 待办清单，点击方框勾选完成 |
| 无序列表、有序列表、引用 | — |
| 代码块 | 等宽字体显示，保留缩进 |
| 插入表格 | 插入 3×3 的表格（第一行为表头）。光标在表格中时，此按钮变为 **表格操作**：在下方插入行、在右侧插入列、删除当前行、删除当前列、删除表格 |
| 插入图片 | 从手机相册选择图片，插入到光标处（见第 6 节） |
| 链接 | 给选中的文字加链接；光标在链接中时可以修改，清空地址即可移除链接。只支持 http、https、mailto、tel 链接 |
| 打开链接 | 光标在链接中时出现，确认后用浏览器等应用打开 |
| 分隔线 | 插入一条横线 |

工具栏可以左右滑动。按钮高亮表示光标处已有该格式。

### Markdown

在源码中直接书写 Markdown，工具栏与工作日志相同（见 [03 工作日志](03-工作日志.md) 第 3 节），另有 **插入图片**。点击 **预览** 查看排版效果，正文中的图片也会显示。

### 两种方式的区别

两种方式保存的都是 Markdown，所以可以随时切换，也方便以后导出。因此富文本只提供 Markdown 能表达的格式：不支持文字颜色、下划线和对齐方式。

用富文本方式打开一篇笔记时，编辑器会把格式整理一次（例如对齐表格的列宽）。只有你真正修改了内容，整理后的结果才会保存。

## 4. 收藏、置顶与删除

- 顶部的 **星标** 按钮：收藏或取消收藏。
- 右上角 **⋮** 菜单：
  - **置顶 / 取消置顶**
  - **修订历史**：查看并恢复以前的版本（见第 8 节）
  - **删除**：删除后其他设备上也会删除，附件一并删除

## 5. 文件夹、标签与关联

点击顶部的 **ⓘ** 按钮打开信息面板。按钮上有小圆点时，表示这篇笔记已有标签或关联。

### 文件夹

点击 **文件夹** 一行，选择要放入的文件夹，或选择"未分类"。

在笔记列表的 **文件夹与标签** 面板中管理文件夹：

- 点击"文件夹"右侧的按钮 **新建文件夹**（名称最多 50 字）。
- 点击文件夹右侧的 **⋮**：
  - **新建子文件夹**：文件夹可以多层嵌套
  - **重命名**
  - **移动到…**：移到其他文件夹下，或移到顶层。不能移到自己的子文件夹中
  - **删除**：文件夹中的笔记和子文件夹移到上一级，**不会被删除**

### 标签

在信息面板的 **标签** 区点击 **添加**，输入标签名（最多 30 字），也可以点击下方用过的标签直接添加。点击标签上的 × 移除。

在 **文件夹与标签** 面板中点击标签右侧的 **⋮**：

- **重命名**：所有笔记上的这个标签一起改名；新名称已存在时两个标签合并
- **删除**：从所有笔记上移除这个标签，笔记本身不会被删除

### 关联到工作日志

在信息面板的 **关联的工作日志** 区点击 **关联**，可以按日期、地点或内容筛选，选择要关联的日志。一篇笔记可以关联多条日志。

关联是双向的：工作日志编辑页底部的 **关联的笔记** 区会列出关联了这条日志的笔记。在工作日志中也可以：

- **新建**：新建一篇笔记并自动关联到这条日志
- **关联**：选择已有的笔记，可以按标题、内容或标签筛选
- 点击笔记右侧的 **取消关联**

## 6. 附件

信息面板底部的 **附件** 区与工作日志相同：可以添加图片、PDF、音频、文档等文件，单个不超过 100MB。

| 类型 | 点击后 |
|---|---|
| 图片 | 全屏查看，可以双指缩放 |
| PDF | 在 App 内阅读，可以缩放、翻页；右上角可以用其他应用打开 |
| 音频 | 在 App 内播放，可以拖动进度条 |
| 其他文件 | 用手机中合适的应用打开 |

**录音**：点击附件区的 **录音**，首次使用时需要允许麦克风权限。点击 **开始录音**，结束时点击 **停止并保存**，录音（AAC 格式，.m4a）会作为附件上传。录音过程中关闭面板，录音会被丢弃。

**正文中的图片**：用工具栏的 **插入图片** 插入的图片会显示在正文中，同时出现在附件列表里。在附件列表中删除这张图片后，正文中显示"图片无法显示"。

为了安全，正文中的网络图片（例如从其他地方粘贴来的图片链接）不会加载，只显示图片的说明文字。

## 7. 多设备同时编辑

规则与工作日志相同（见 [04 多设备同步](04-多设备同步.md)），笔记还有以下特点：

- 正文：两台设备修改了不同的段落时会自动合并；你正在输入时收到其他设备的修改，也会合并到编辑器中，不会打断输入。
- 标签和关联：两台设备同时添加的标签（或关联）都会保留。
- 文件夹：在一台设备上删除文件夹的同时，另一台设备把笔记放进了这个文件夹，这篇笔记会显示在"未分类"中。

## 8. 修订历史

在 **⋮ → 修订历史** 中可以查看修改前、冲突中未被采用、删除前的版本，显示当时的标题和正文。点击 **恢复此版本** 恢复标题和正文。需要联网。

## 9. 数据安全

- 笔记的标题、正文、标签和文件夹名与工作日志一样：传输时除 HTTPS 外还会再加密一层，保存到服务器时也以密文存储（见 [03 工作日志](03-工作日志.md) 第 7 节）。
- 富文本编辑器运行在 App 内，不访问网络；正文中的内容不能执行脚本，也不会加载网络图片。
- 退出登录时本机的笔记会被清除，重新登录后自动从服务器恢复；注销账号会永久删除全部笔记和附件。
