# 08 搜索与导出

> 适用版本：v0.7.0 及以上

## 1. 全局搜索

搜索覆盖工作日志、笔记、备忘录和记账四个模块，全部在手机上完成，不联网也能用。

### 打开搜索

- **手机竖屏**：点击顶栏右侧的放大镜。
- **平板或横屏**：点击侧栏最上方的 **搜索**。

在某个模块里打开搜索时，默认只搜这个模块，例如在笔记里打开就只搜笔记。点 **全部** 可以改为搜索全部模块。

### 输入关键词

- 输入后稍等片刻即显示结果，不用按回车。
- 中文、英文都能按任意片段匹配，例如输入"评审"能找到"季度评审会议"。英文不区分大小写。
- 多个关键词用空格分开，结果需要同时包含全部关键词，例如 `周五 房租`。最多 5 个关键词。
- 每个模块搜索的内容：

| 模块 | 搜索的内容 |
|---|---|
| 工作日志 | 地点、内容 |
| 笔记 | 标题、正文、标签 |
| 备忘录 | 内容 |
| 记账 | 流水的备注，以及它的分类、账户和借贷对方 |

记账的搜索也会看分类和账户：搜"餐饮"能找到所有餐饮分类（包括"午餐"等二级分类）的流水；搜"支付宝"能找到支付宝账户的收支和转账；搜借贷对方的名字能找到和他有关的借出、收款等流水。

### 筛选

搜索框下方有一排筛选：

- **模块**：点选一个或多个模块，只看这些模块的结果；点 **全部** 取消筛选。
- **时间**：点 **时间不限** 选择起止日期。工作日志、流水按记录的日期，备忘录按提醒时间，笔记按最后修改时间。点日期范围右侧的 × 清除。

### 查看结果

- 结果按模块分组，每组标题后面是条数。组内按日期从新到旧排列。
- 关键词在标题和摘要中高亮显示。流水的右侧显示金额。
- 点击一条结果打开它。返回后结果会重新搜索，修改过的内容也能反映出来。
- 结果最多显示最近的 200 条。超出时列表顶部会提示，可以添加关键词或筛选条件缩小范围。

> 更新到 v0.7.0 后第一次打开 App 时，会为已有的数据建立搜索索引，数据很多时启动会稍慢一点，只有这一次。

## 2. 数据导出

可以把数据导出为常用格式，用于备份、在电脑上查看或迁移到其他软件。

### 发起导出

从 **设置 → 数据导出** 进入：

1. 勾选要导出的模块，默认全选。
2. 需要图片、文档等附件时，打开 **包含附件文件**。附件可能很大，导出和下载都会慢一些。
3. 点击 **开始导出**。

导出在服务器上生成，可以离开这个页面。完成后，你登录的所有手机都会收到"导出已完成"的通知（需要已允许 App 发送通知）。如果收到了不是自己发起的导出通知，请立即在 **帐号 → 登录设备** 中下线不认识的设备并修改密码。

- 同一时间只能进行一个导出。
- 24 小时内最多发起 5 次导出，删除导出不会恢复次数。

### 下载

在 **最近的导出** 中找到已完成的导出，点击下载按钮。文件下载完成后会打开系统分享面板，可以：

- 保存到手机的"文件"中；
- 通过微信、QQ、邮件等发到电脑。

文件名形如 `即刻日志导出-20261011-0930.zip`。

**导出文件在服务器上保留 24 小时**，之后自动删除，状态变为"已过期"。如果不再需要，也可以点删除按钮提前删除。

> ⚠️ 导出文件**没有加密**，任何拿到文件的人都能看到其中的内容。请妥善保管，不要发到公共群聊或公共网盘。

### 导出文件里有什么

zip 解压后的目录如下（只包含勾选的模块）：

| 位置 | 内容 | 用什么打开 |
|---|---|---|
| `README.txt` | 导出时间、包含的模块和文件说明 | 记事本 |
| `data.json` | 所选模块的全部原始数据，用于备份或迁移 | 文本编辑器、程序 |
| `工作日志/工作日志.xlsx` | 每篇一行：日期、地点、内容、附件数 | Excel、WPS |
| `工作日志/2026-10-09.md` 等 | 每篇一个 Markdown 文件 | Typora、Obsidian、记事本 |
| `笔记/<文件夹>/<标题>.md` | 每篇笔记一个文件，按文件夹存放；开头列出标题、标签、是否收藏和修改时间 | Typora、Obsidian |
| `备忘录/备忘录.ics` | 日历文件，含提醒时间，可以导入手机或电脑的日历 | 日历、Outlook |
| `备忘录/备忘录.csv` | 时间、是否全天、内容、提醒、是否完成 | Excel、WPS |
| `记账/记账.xlsx` | 流水、账户、分类、借贷四个工作表，金额单位为元 | Excel、WPS |
| `记账/流水.csv` 等 | 与上面四个工作表一一对应 | Excel、WPS |
| `附件/` | 勾选"包含附件文件"时才有，Markdown 中的图片和附件链接指向这里 | — |

说明：

- 笔记标题中的 `/`、`?` 等字符在文件名中会换成 `_`。同一文件夹里有同名的笔记时，后面的会加上 `(2)`、`(3)`。
- 备忘录的时间按发起导出的手机所在时区显示。已完成的备忘录在日历中标为"[已完成]"，并且不再提醒。
- 导出的是服务器上的数据。还没同步到服务器的修改不会包含在内，导出前请确认同步状态正常。
- CSV 中以 `=`、`+`、`-`、`@` 开头的文字前面加了一个单引号 `'`，防止 Excel 把它当作公式执行；xlsx 中没有这个单引号。
- 极少数情况下有记录无法读取，`README.txt` 中会写明未导出的条数。
- 下载到手机上的导出文件放在 App 的临时目录，下次下载或退出登录时删除。

## 3. 常见问题

**搜不到刚在另一台手机上写的内容？**
搜索只查本机数据。等这台手机同步完成后再搜（见[多设备同步](04-多设备同步.md)）。

**导出一直显示"排队中"或"正在生成"？**
内容很多，或者包含大量附件时，生成可能需要几分钟。页面会自动刷新状态，也可以下拉手动刷新。如果最终失败，可以重新发起。

**没收到导出完成的通知？**
检查是否允许了 App 的通知（见[备忘录](06-备忘录.md)中的通知权限说明）。没有通知也不影响导出，回到 **设置 → 数据导出** 就能看到状态。

**用 Excel 打开 CSV 是乱码？**
导出的 CSV 是 UTF-8 编码，新版 Excel 和 WPS 都能正确识别。如果仍然乱码，改用同目录下的 xlsx 文件。
