# 03 工作日志

> 适用版本：v0.3.0 及以上

工作日志用来记录每天的工作：日期、工作地点、工作内容和附件。内容随时可以修改，修改会自动保存并同步到你登录的其他设备。

## 1. 日志列表

登录后默认进入工作日志（也可以从 **导航栏 → 工作日志** 进入）。

- 日志按日期倒序排列，并按月份分组。每条显示日期、星期、工作地点和内容摘要。
- 摘要右侧的小图标表示同步状态：

| 图标 | 含义 |
|---|---|
| ☁↑ 云朵上传 | 已保存在本机，等待同步到服务器 |
| ⇄ 分叉 | 与其他设备的修改冲突，有一个未被采用的版本可以查看（见第 5 节） |
| ⟳! 同步异常 | 这条修改没有被服务器接受，再次修改后会重新尝试 |

- 在列表中向下拉，可以立即同步一次。

## 2. 写日志

点击右下角的 **写日志**，会新建一篇今天的日志并进入编辑页。

| 项目 | 说明 |
|---|---|
| 日期 | 点击顶部的日期可以修改，默认是今天 |
| 工作地点 | 最多 100 字。输入时会联想你用过的地点，点击即可填入 |
| 工作内容 | 支持 Markdown，最多 10 万字 |
| 附件 | 图片、PDF、音频、文档等，单个不超过 100MB（见第 4 节） |

**不需要点保存**：停止输入 1 秒后自动保存到本机，离开页面时也会立即保存。顶部日期下方显示当前状态：

- **已同步**：已经保存到服务器
- **已保存在本机，等待同步**：稍后自动上传
- **已保存在本机，联网后自动同步**：当前离线，联网后自动上传
- **同步失败：内容未被服务器接受**：请检查内容后再修改一次

## 3. 用 Markdown 排版

编辑框上方的工具栏可以快速插入格式：

| 按钮 | 效果 |
|---|---|
| 标题 | 在当前行行首加 `## `，再点一次取消 |
| 加粗 | 用 `**` 包住选中的文字 |
| 列表 | 在当前行行首加 `- ` |
| 待办 | 在当前行行首加 `- [ ] `，完成后把空格改成 `x` |
| 代码块 | 插入一对 ``` |
| 表格 | 插入一个两列表格 |
| 预览 / 编辑 | 切换到排版后的效果，再点一次回到编辑 |

## 4. 附件

在编辑页底部的 **附件** 区点击 **添加**，从手机中选择一个或多个文件。

- 文件先复制到 App 内，再在后台上传；上传前显示"等待上传"。新建的日志会在同步到服务器后再上传附件。
- 点击已上传的附件，会下载（首次）并用手机中合适的应用打开。下载后会校验文件完整性。
- 上传失败时会显示原因（例如附件空间已用完），点击右侧的 **重试** 再次上传。
- 点击附件右侧的删除图标可以删除附件，其他设备上也会一并删除。
- 每个账号的附件总空间为 2GB。

附件文件名在传输和保存时都经过加密；文件本身保存在私有的对象存储中，只能通过 10 分钟内有效的临时链接下载。

## 5. 修订历史与冲突版本

点击编辑页右上角的 **修订历史**（时钟图标）可以查看这篇日志过去的版本：

| 类型 | 何时产生 |
|---|---|
| 修改前的版本 | 换了一台设备修改，或距上次修改超过 10 分钟后再次修改时，保留修改前的内容 |
| 冲突中未被采用的版本 | 两台设备同时修改了同一处内容，最后修改的一方被采用，另一方保存在这里 |
| 删除前的版本 | 日志被删除前的内容 |

点击某个版本查看内容，点击 **恢复此版本** 即可用它覆盖当前内容（恢复本身也是一次修改，会同步到其他设备）。查看修订历史需要联网。

两台设备修改**不同段落**时，内容会自动合并，不会产生冲突。只有修改了同一处时，才会出现冲突提示：编辑页顶部显示黄色提示条，点击即可进入修订历史查看另一个版本。

## 6. 删除日志

点击编辑页右上角的删除图标，确认后删除。日志的附件会一并删除，其他设备上也会同步删除。

## 7. 数据安全

- 工作地点和工作内容在传输时除 HTTPS 外还会再加密一层，保存到服务器时也以密文存储（每个账号一把独立的密钥）。
- 退出登录时，本机保存的日志会被清除，重新登录后自动从服务器恢复。如果还有未同步的修改，退出前会提醒你。
- 注销账号会永久删除你的全部日志、附件和密钥。
