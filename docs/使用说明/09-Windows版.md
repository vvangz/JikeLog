# 09 Windows 版

> 适用版本：v1.1.0 及以上

Windows 版与 Android 版是同一个应用：用同一个账号登录，数据在手机和电脑之间实时同步。要求 Windows 10（1809）及以上的 64 位系统。

## 1. 安装

Windows 版以 MSIX 安装包发布，使用即刻日志自己的证书签名。**第一次安装前**要先让电脑信任这张证书，以后升级不用再做。

1. 打开 [GitHub Release 页面](https://github.com/vvangz/JikeLog/releases/latest)，下载两个文件，放在同一个文件夹：
   - `jikelog-<版本>.msix`：安装包
   - `jikelog-windows.cer`：证书
2. 信任证书（二选一，都需要管理员权限）：
   - **图形界面**：双击 `jikelog-windows.cer` → **安装证书** → 存储位置选 **本地计算机** → 选 **将所有的证书都放入下列存储** → 浏览，选 **受信任的人** → 完成。
   - **命令**：在该文件夹中以管理员身份打开 PowerShell，执行：
     ```powershell
     Import-Certificate -FilePath .\jikelog-windows.cer -CertStoreLocation Cert:\LocalMachine\TrustedPeople
     ```
3. 双击 `jikelog-<版本>.msix`，点击 **安装**。

> 这张证书只放进"受信任的人"，用来确认安装包确实来自即刻日志；它不是根证书，不能用来签发其他证书。证书的 SHA-1 指纹为 `F44C3F6641E3DB7CE741AB769F6BE2063E4AB890`，可以在证书的"详细信息"中核对。

**升级**：下载新版本的 `.msix` 双击安装即可，数据保留。

**卸载**：开始菜单中右键"即刻日志"→ 卸载。本机数据随之删除，服务器上的数据不受影响。

## 2. 与 Android 版的区别

| 功能 | Windows 版 |
|---|---|
| 笔记编辑 | 只有 Markdown 编辑（工具栏同 Android 的 Markdown 模式）。在手机上用富文本写的笔记也以 Markdown 打开，内容不会丢失，回到手机上仍是富文本 |
| 备忘提醒 | 由 Windows 通知弹出，App 关闭后照常提醒。可在 Windows 的"设置 → 系统 → 通知"中管理 |
| 同步到系统日历 | 不提供 |
| 数据导出 | 下载时选择保存的文件夹（不是分享面板），保存后提示文件位置 |
| 打开附件 | 用电脑上对应的默认应用打开。可执行文件（如 `.exe`、`.bat`）不会直接运行，而是打开所在文件夹 |
| 录音附件 | 需要麦克风权限，第一次录音时 Windows 会询问 |

## 3. 快捷键

| 快捷键 | 作用 |
|---|---|
| Ctrl+F | 打开搜索（在某个模块中时默认只搜该模块） |
| Ctrl+N | 在当前模块中新建：写日志、新建笔记、新建备忘、记一笔 |

快捷键在模块首页生效；打开某条记录或对话框时不响应。

## 4. 窗口

- 窗口可以自由调整大小。宽度超过 840 时侧栏常驻；较窄时与手机相同，点左上角图标展开侧栏。
- 最小窗口为 400×560。
