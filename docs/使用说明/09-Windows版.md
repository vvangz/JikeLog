# 09 Windows 版

> 适用版本：v1.1.0 及以上

Windows 版与 Android 版是同一个应用：用同一个账号登录，数据在手机和电脑之间实时同步。要求 Windows 10（1809）及以上的 64 位系统。

## 1. 安装

Windows 版以 MSIX 安装包发布，使用即刻日志自己的证书签名。**第一次安装前**要先让电脑信任这张证书，以后升级不用再做。

1. 打开官网的[下载页](https://www.pingvv.top/download#windows)（下载慢时可以用 [GitHub Release 页面](https://github.com/vvangz/JikeLog/releases/latest)），下载两个文件，放在同一个文件夹：
   - `jikelog-<版本>.msix`：安装包
   - `jikelog-windows.cer`：证书
2. 先按下方说明核对证书指纹，再信任证书（二选一，都需要管理员权限）：
   - **图形界面**：双击 `jikelog-windows.cer` → **安装证书** → 存储位置选 **本地计算机** → 选 **将所有的证书都放入下列存储** → 浏览，选 **受信任的人** → 完成。
   - **命令**：在该文件夹中以管理员身份打开 PowerShell，执行：
     ```powershell
     Import-Certificate -FilePath .\jikelog-windows.cer -CertStoreLocation Cert:\LocalMachine\TrustedPeople
     ```
3. 双击 `jikelog-<版本>.msix`，点击 **安装**。

**导入前先核对证书指纹**：双击 `jikelog-windows.cer` → **详细信息** → **指纹**，应为：

- SHA-1：`F44C3F6641E3DB7CE741AB769F6BE2063E4AB890`
- SHA-256：`87:72:FE:C3:1F:65:82:01:E1:5B:27:ED:B8:42:F1:1D:B2:BE:73:E5:71:1D:A0:59:56:B8:1C:2F:D5:E2:95:BA`

指纹也保存在仓库的 [`deploy/windows/jikelog-windows.cer`](../../deploy/windows/jikelog-windows.cer) 与提交历史中，可以从那里再核对一次，不要只相信下载页面。

> **关于这张证书**：它只放进"受信任的人"，不是根证书，不能用来签发其他证书。但电脑信任它之后，任何用它签名的安装包都能在这台电脑上安装运行。如果将来公告证书私钥泄露，请立即删除它：按 Win+R 输入 `certlm.msc` → **受信任的人** → **证书** → 删除 `JikeLog`。不再需要升级时也可以删除，已安装的即刻日志不受影响。

**升级**：下载新版本的 `.msix` 双击安装即可，数据保留。

**卸载**：开始菜单中右键"即刻日志"→ 卸载。本机数据随之删除，服务器上的数据不受影响。

## 2. 与 Android 版的区别

| 功能 | Windows 版 |
|---|---|
| 笔记编辑 | 只有 Markdown 编辑（工具栏同 Android 的 Markdown 模式）。在手机上用富文本写的笔记也以 Markdown 打开，内容不会丢失，回到手机上仍是富文本 |
| 备忘提醒 | 由 Windows 通知弹出，App 关闭后照常提醒。可在 Windows 的"设置 → 系统 → 通知"中管理 |
| 同步到系统日历 | 不提供 |
| 数据导出 | 下载时选择保存的文件夹（不是分享面板），保存后提示文件位置 |
| 打开附件 | 图片、PDF、文本、Office 文档（不含宏）、压缩包、音视频用电脑上的默认应用打开；其他类型（程序、脚本、快捷方式、含宏的文档、网页等）只打开所在文件夹，由你决定是否打开。打开的是标记为"来自互联网"的副本，Office 会以受保护视图打开 |
| 录音附件 | 需要麦克风权限，第一次录音时 Windows 会询问 |

## 3. 快捷键

| 快捷键 | 作用 |
|---|---|
| Ctrl+F | 打开搜索（在某个模块中时默认只搜该模块） |
| Ctrl+N | 在当前模块中新建：写日志、新建笔记、新建备忘、记一笔 |

Ctrl+N 在四个模块的首页生效；Ctrl+F 在主界面（含设置、账号页）都可以用。打开某条记录、对话框或底部面板时，快捷键不响应。Android 手机外接键盘时同样可用。

## 4. 窗口

- 窗口可以自由调整大小。宽度超过 840 时侧栏常驻；较窄时与手机相同，点左上角图标展开侧栏。
- 最小窗口为 400×560。
