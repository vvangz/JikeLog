# 04 多设备同步

> 适用版本：v0.3.0 及以上

同一个账号可以在多台设备上同时使用。所有修改先保存在本机，再自动同步到其他设备，离线时也能正常记录。

## 1. 什么时候同步

不需要手动操作，以下时机都会自动同步：

- 打开 App、登录之后
- 修改内容后约 2 秒
- 其他设备有修改时：App 在前台时会实时收到通知并立即拉取
- App 从后台回到前台、网络恢复时
- 在前台时每 5 分钟检查一次

也可以在工作日志列表中下拉，或点击导航栏底部的同步状态，立即同步一次。

## 2. 同步状态

导航栏底部（帐号名下方）显示同步状态：

| 显示 | 含义 |
|---|---|
| 已同步 · 时间 | 最近一次同步完成的时间 |
| 同步中… | 正在上传或下载 |
| N 条待同步 | 有尚未上传的修改，稍后自动上传 |
| 离线 · N 条待同步 | 当前没有网络，修改已保存在本机，联网后自动上传 |
| 同步失败，稍后自动重试 | 服务器暂时不可用，会自动重试 |

## 3. 两台设备同时修改

即刻日志按 **字段** 合并修改，而不是整篇覆盖：

- **修改了不同的字段**（如一台改地点、一台改内容）：两边的修改都会保留。
- **修改了同一篇日志正文的不同段落**：自动合并，两边的修改都会保留。
- **修改了同一处**：采用最后修改的版本（"最后修改覆盖"），另一版本保存在修订历史中，日志上会显示冲突提示，可随时查看和恢复（见 [03 工作日志 第 5 节](03-工作日志.md#5-修订历史与冲突版本)）。
- **一台删除、一台修改**：删除优先，被丢弃的修改同样保存在修订历史中。

"最后修改"按修改发生的时间判断，而不是按上传的先后。请保持手机的系统时间准确（开启"自动设置时间"）：如果设备时间比实际快很多，修改会被服务器拒绝，并提示校准时间。

## 4. 离线使用

离线时可以照常新建、修改、删除日志，附件也可以先添加（联网后上传）。联网后，所有修改会按上面的规则自动合并。

## 5. 退出登录与切换账号

主动退出登录、注销账号，或换一个账号登录时，本机保存的数据和附件文件会被清除，避免下一个账号看到上一个账号的内容。重新登录后，数据会从服务器自动恢复。如果还有没同步的修改，退出前会先尝试上传，仍有未上传的修改时会提醒你。

登录失效（长时间未使用、在其他设备上修改了密码或下线了本设备）时，App 会回到登录页，但**不会**清除本机数据。用同一个账号重新登录后，还没同步的修改会继续上传；换成其他账号登录时才会清除。
