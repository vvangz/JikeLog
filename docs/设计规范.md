# 设计规范

所有颜色、字号、间距、圆角、动效时长都定义在 [`packages/design-tokens/tokens`](../packages/design-tokens/tokens) 中，执行 `pnpm tokens` 生成：

- Flutter：`apps/mobile/lib/app/theme/jk_tokens.g.dart`（`JkColorTokens.light/dark`、`JkTokens`）
- Web：`apps/admin-web/src/theme/tokens.gen.css`（CSS 变量 `--jk-*`）、`tokens.gen.ts`（供 Ant Design 主题使用）

**不要在业务代码里直接写颜色值或尺寸数字。** 需要新值时先加令牌。

## 颜色

主色为咖色。浅色主题用 `#6F4E37`；深色主题提亮为拿铁色 `#C8A27C`，保证在深色背景上的对比度。

| 语义 | 浅色 | 深色 | 用途 |
|---|---|---|---|
| primary | `#6F4E37` | `#C8A27C` | 主按钮、选中态、链接、入口图标 |
| background | `#FAF7F2` 奶油白 | `#171311` 深咖黑 | 页面底色 |
| surface | `#FFFFFF` | `#221C19` | 卡片、弹窗、侧栏 |
| textPrimary | `#2A2420` | `#EDE6DF` | 正文 |
| textSecondary | `#5E554D` | `#D1C6B9` | 辅助文字 |
| success | `#2F7A4D` | `#7CC59A` | 成功、同步完成 |
| warning | `#93590A` | `#E5B567` | 警告、即将到期 |
| error | `#B3261E` | `#F2A39C` | 错误、删除 |
| info | `#2F6596` | `#93BDE4` | 提示、信息 |

每种状态色都有 `onX`（放在该色上的文字色）、`xContainer`（浅底）和 `onXContainer`（浅底上的文字色）。

**对比度**：`packages/design-tokens/test/contrast.test.mjs` 会自动校验以下要求（WCAG 2.2），不达标时 CI 失败：

- 正文与背景 ≥ 7
- 辅助文字 ≥ 4.5
- 状态色上的文字 ≥ 4.5
- 状态色与界面元素之间 ≥ 3

## 字体

- `Space Grotesk`：英文、数字、金额
- `MiSans`：中文（作为回退字体自动生效）
- 字号：12（说明）、14（正文）、16（大正文）、18（标题）、22（大标题）、28（展示）
- 字重：400 / 500 / 600 / 700；行高：1.25 / 1.5 / 1.7

## 间距与圆角

- 间距（4 的倍数）：2、4、8、12、16、24、32
- 圆角：6（小控件）、10（按钮、输入框、卡片）、16（弹窗、底部面板），以及全圆角

## 图标

采用 Lucide 风格：24px 栅格、1.5px 描边、圆角端点、只用线框。四个模块的图标按同一规格自绘。品牌标志由线框笔记本加实心圆点构成。Flutter 端由 `JkLogo` 绘制，Web 端为 `logo.svg`。

## 导航

- 左上角放入口图标（品牌标志），点击后侧栏**自上而下展开**（时长 320ms，曲线 `cubic-bezier(0.2, 0, 0, 1)`；系统开启"减少动态效果"时不播放动画）
- 侧栏**上部**是四个模块入口：工作日志、笔记、备忘录、记账；**下部**是设置、账号、同步状态
- 响应式断点：
  - 宽度 < 600：抽屉，浮层覆盖内容
  - 600–840：NavigationRail
  - \> 840：侧栏常驻，并采用列表+详情的双栏布局

## 状态规范（v0.2.0 起在 `shared/ui` 统一实现）

| 状态 | 规范 |
|---|---|
| 加载 | 列表、卡片用骨架屏；按钮内用小号进度圈；整页加载超过 300ms 才显示加载态，避免闪烁 |
| 空状态 | 线框插图 + 一句说明 + 主操作按钮（如"写第一篇日志"） |
| 错误 | 错误色图标 + 用户能看懂的原因 + "重试"按钮；不展示错误码以外的技术细节 |
| 表单 | 标签在上，必填项加星号；失焦时校验，错误提示放在字段下方，使用错误色 |
| 弹窗 | 确认类弹窗把主操作放在右侧；删除等危险操作使用错误色按钮，并写明后果 |
| 表格/列表 | 斑马纹关闭，用分隔线区分行；金额右对齐，使用等宽数字（Space Grotesk tabular） |
